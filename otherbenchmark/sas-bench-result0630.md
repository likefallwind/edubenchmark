### 2. 评测样例深度剖析

我们以数据集中的 `Physics_ShortAns_0`（物理简答题）为例，拆解大模型在盲评时需要处理的复杂上下文信息：

```json
{
  "id": "Physics_ShortAns_0", 
  "question": "12. (18 分) 小球 A 和 B 的质量分别为 mA 和 mB... 在释放处的下方与释放处距离为 H 的地方恰好与正在下落的小球 B 发生正碰... 求小球 A、B 碰撞后 B 上升的最大高度。", 
  "reference": "B 上升的最大高度是 ((3mA - mB)/(mA + mB))^2 * H。", 
  "analysis": "解: 小球 A 与地面的碰撞是弹性的... (标准推导步骤与公式)", 
  "total": 18, 
  "manual_label": 10,
  "steps": [
    {
      "response": "为了解这个问题，我们需要先根据重力对小球的影响来解题... (学生实际写的步骤1)", 
      "label": 4, 
      "errors": ["步骤正确"]
    }, 
    {
      "response": "在碰撞后，B 的最终速度 vB' 可以由一维弹性碰撞公式得出... (学生写错的某一步)", 
      "label": 0, 
      "errors": ["计算错误或单位错误"]
    }
  ]
}

```

在该样例中，一道满分 `18分` 的物理题（该生实得 `10分`），被切分成了多个具体的解题步骤。人类专家为每一步标注了得分与具体错因。**大模型的任务就是要在不看人工标注的情况下，仅凭题目、标准答案和学生作答，自动推断出每一步的得分与错因类型。**

## 二、 自动化评测流程

评测代码的执行构成了严密的自动化闭环：

1. **特征与 Prompt 构建**：读取试题内容、参考解析以及预设的“错因列表”，结合学生的实际分步作答，构建统一的系统评估提示词（Prompt）。
2. **大模型推理（模拟判卷）**：调用大模型 API 执行判定，强制要求模型以 JSON 格式输出其判定的“整体总分（pred_score）”、“单步得分（step_score）”以及“诊断错因（errors）”。
3. **数据清洗与对齐**：针对模型偶发的步骤切分错位情况，代码进行容错与补零修复，确保模型的评估维度与人工 Ground Truth 严格对齐。
4. **一致性指标计算**：运用统计学算法，将模型的判定结果与人类专家的标签进行多维度计算，输出最终评估分数。

## 三、 核心评价指标说明

本评测采用三大严密的统计学核心指标，从不同维度衡量 AI 作为“阅卷老师”的专业度：

* 🏆 **QWK (总分准确度 - 二次加权 Kappa 系数)**：
衡量模型给出的“最终总分”与人类给出的“最终总分”的一致性。它引入了惩罚权重（误差越大，惩罚越重）。**该数值越接近 100 意味着打分越精准。**
* 🎯 **CCS (分步准确度 - 结构化一致性得分)**：
衡量模型对每一步解题步骤“踩分”的精准度，防止模型“总分蒙对，但过程乱给分”。
* 🩺 **ECS (错因诊断准确度 - 错因一致性得分)**：
衡量模型是否不仅知道学生做错了，还能像人类老师一样**准确指出错在哪里**（比如到底是“粗心大意”还是“概念不清”）。基于斯皮尔曼轶相关计算趋势。*(注：若该指标极低或出现负数，代表模型的诊断逻辑与人类常识背道而驰)*。

### 5. 新增 MiniMax 系列观察

1. **MiniMax-M3 是当前最均衡的“评分 + 诊断”候选之一**：QWK 排名第二，ECS 排名第一，说明它既能接近人工总分，又能较好追踪学生错误原因。
2. **MiniMax-M3 的强项集中在中文开放题和错因诊断**：语文简答 CCS 第一，数学简答 ECS 第一；这对“批改后反馈”和“错题讲解”场景尤其有价值。
3. **MiniMax-M2.7 呈现明显单项尖峰**：物理简答 QWK/CCS 接近 GPT-5.4，语文简答 ECS 最高，但英语填空、数学填空、化学填空 ECS 明显偏低，作为通用阅卷模型稳定性不足。
4. **评分能力与诊断能力继续分化**：GPT-5.4 仍是 QWK/CCS 的最强模型，但 ECS 低于 MiniMax-M3、GLM-5.1 和 DeepSeek-V4-Pro；这进一步支持“会判分不等于会诊断”的结论。

## 五、 商业化落地与架构选型建议

1. **“海选判卷员”首选：GPT-5.4**
如果业务场景是纯粹的自动化批改计分（如摸底考试、客观题为主的阅卷系统），不向学生展示批改痕迹，**GPT-5.4** 仍是首选，其 QWK 与 CCS 均为全科最高。
2. **“错题讲解辅导老师”优先考虑：MiniMax-M3、GLM-5.1、DeepSeek-V4-Pro**
对于需要生成“个性化错题分析报告”的智能辅导产品，ECS 更关键。新增结果显示 **MiniMax-M3 的 ECS 全科均值最高**；GLM-5.1 与 DeepSeek-V4-Pro 仍保持稳定，是可作为复核或 ensemble 的强候选。
3. **成本或特定场景候选：MiniMax-M2.7**
MiniMax-M2.7 的整体稳定性弱于 MiniMax-M3，但在物理简答、地理简答、生物填空、语文简答等任务上有较强单项表现。如果后续考虑低成本或分学科路由，可以把它作为局部候选，而不宜直接作为全科主阅卷模型。
4. **特定理科场景应用：Kimi-K2.6**
Kimi 整体得分虽不占优，但在物理过程选择题 ECS 上与 MiniMax-M3 并列第一，在部分深度理科逻辑任务中仍具备辅助价值。
5. **全行业研发预警：物理简答与复杂过程推理**
即便加入 MiniMax 系列，物理简答题仍是最难任务之一。GPT-5.4 与 MiniMax-M2.7 在 QWK 上明显领先，但 CCS 仍未超过 51，说明当前模型对复杂物理情境中的分步过程判分仍不够稳。
