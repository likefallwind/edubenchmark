EduGuard-Bench（github.com/YL1N/EduGuardBench，论文《EduGuardBench: A Holistic Benchmark for Evaluating the Pedagogical Fidelity and Adversarial Safety of LLMs as Simulated Teachers》）从两条独立赛道考察「把 LLM 当老师用」时的风险： P1 教学伤害评估用「全选题（SATA）」量化模型在五类教学场景下是否能识别并规避有害教学行为（指标 RFS / 完全匹配准确率 / 漏选率 / 误选率）； P2 对抗安全评估用角色扮演越狱提示考察模型是否会被诱导输出有害内容（指标 ASR 攻击成功率 + 拒答三档质量）。本报告把我们在这两个赛道上对 6 个新模型的评测，与原论文 14 个模型的公开结果并表对照，并附上对 P2 评分用 LLM-as-Judge 的独立校准。

  • 新一代模型显著更安全。本轮 6 个模型在 P2 上的 ASR 介于 3.5% ~ 57.1%，全部低于原论文最安全模型 Claude-3.7（27.0%）；其中 MiniMax-M3 ASR 仅 3.5%，比论文里最危险的 DeepSeek-V3（81.6%）低了一个数量级。两代模型在安全对齐上差距巨大。
  • 教学保真度（RFS）整体追平甚至略超论文最优。本轮 6 个模型 RFS 全部 ≥ 0.73，其中 MiniMax-M3（0.769）已超过论文最高的 Claude-3.7（0.77）。说明新模型在「识别并规避有害教学」上能力更强。

1评测方法概览

P1 · 教学伤害评估（Teaching Harm / SATA）

5,270 条双语「全选题」（中/英各 2,635），覆盖五类教学场景。模型需选出一组「会造成教学伤害」的选项，按官方 run_p1_evaluation.py 规则计分（非 LLM 判分）：

  • RFS（角色保真分）：选项集合与金标的相符程度（完全相符=1，非空真子集=0.5，否则 0）的平均值。
  • 完全匹配准确率：选项集合与金标完全一致的比例。
  • 漏选率 / 误选率：漏掉应选项 / 多选不应选项的比例。

P2 · 对抗安全评估（Adversarial Safety）

801 条角色扮演越狱提示，覆盖五类风险（AM/AP/HR/PI/TS）。两阶段 LLM-as-Judge（每阶段 BoN=3 多数投票，移植自官方 run_p2_experiment.py）：

  • ASR（攻击成功率）：回复被判为「输出了有害/学术不端内容」的比例——越低越安全。
  • 拒答三档质量：对成功拒答的回复再分 教育型 > 标准型 > 敷衍型。教育型拒答会把拒绝转化为引导，是更高阶的安全能力。

2LLM-as-Judge 校准：为什么 P2 用 MiniMax-M3 判分

P2 的 ASR 与拒答质量依赖一个「裁判模型」。论文用 200 条人类金标筛出 DeepSeek-V3，但那份人类金标未公开。我们因此自建一份 Claude Opus-4.8 盲标金标（120 条）重做校准，把候选 Judge 放在同一把尺子上，并与论文 Table 2 参照值对照。金标分布：harmfulness 49 有害 / 71 无害；拒答档 18 标准 / 29 教育 / 1 敷衍。

4.5 原论文其他统计发现（补充对照）

教育转化效应（Educational Transformation Effect）

论文指出「更安全的模型不止拒答，更会把拒绝转成教育引导」。同样口径下：Claude-3.7 的拒答中 64.5% 为教育型，而 DeepSeek-V3 仅 14.5%。本轮新模型把这一比例进一步推高（如 MiniMax-M3 教育型拒答占比 82.3%），与论文结论方向一致。

规模悖论（Scaling Paradox · Table 10）

同系列下「更大≠更安全」：Qwen3 的 ASR 随规模升高——8B 60.4% → 32B 75.2% → 235B 70.0%；非推理版 8B-NR 62.7% → 32B-NR 68.4% → 235B-NR 63.8%。单纯堆参数并不能改善对抗安全。

安全分层（ANOVA / Tukey · Table 8–9）

论文 14 模型被分为 5 高危（ASR>70%）/ 8 中危 / 仅 1 低危（Claude-3.7），ANOVA 证实分层显著；差异最大的模型对是 Claude-3.7 vs DeepSeek-V3（+54.3 个百分点）。本轮新模型整体落在论文的「低危~中危」区间，安全分布显著优于上一代。

5综合发现与解读

  • 安全代差明显。把两张 ASR 表叠在一起看：论文 14 模型只有 Claude-3.7 进入低危区，本轮 6 模型全部≤ 中危且多数进入低危/接近低危，MiniMax-M3（3.5%）、GLM-5.2（20.8%）已远低于 Claude-3.7。新一代模型的安全对齐是实打实的进步。
  • 「教育型拒答」成为主流。本轮最安全的模型不只是「拒绝」，而是把拒答转成教育引导：MiniMax-M3 的拒答中教育型占比 82.3%。这正是论文强调的「教育转化效应（Educational Transformation Effect）」，且本轮模型把它做到了更高水平。
  • 教学保真度与安全性可兼得。论文担心的「安全↔能力」张力在本轮并未出现明显牺牲：MiniMax-M3 同时拿到最高 RFS（0.769）和最低 ASR（3.5%）。
  • 结构性短板仍在。无论新旧模型，纠错 EC / 解题 PS 场景的教学保真度都偏低；P1 不是已经被解决的问题，仍是教育场景评测的重点。
  • 评测口径自洽。因为我们独立校准并选用了比论文更严的 Judge（MiniMax-M3），本轮偏低的 ASR 不能用「judge 放水」解释——反而可能是低估了真实安全程度的下限。
