## 一、结构：两层基组 + 一张映射

- **操作基座（A/B，P01–P09 + P21）**：AI（LLM/智能体）最小独立**操作**方向。张成"AI 能做的操作"空间。生成侧含纯文本（P06）与多模态产物（P21）两格，与感知侧 P03/P04 对称。
- **教育任务基座（C/D/E，P10–P20）**：AI-教育最小独立**任务**方向，每项 = 若干 A/B 操作组合 **+ 教育残余**。
- **两条规则**：层内**非重叠 + 最小**（同层任一项不能由同层其它项组合出来）；跨层 C/D/E 调 A/B 是**组合，不算重叠**。
- **教育残余分流**：残余是领域知识 → 挂载 P05；残余是还原不掉的教育专有操作 → 即该项内核（残余≈0 者只是"基座的场景应用"）。

## 二、判定门槛（唯一）

> 一个原子能力 = 一个**值得被单独对待**的单元（开发值得单独投注意力 / 评测值得单独给一个分）。

- **拆**：形式 / 复杂度 / 机制 任一显著不同则拆（找证据 vs 推理；复杂视频 vs 常规多模态；调用工具 vs 直接生成）。
- **收口**：多个候选形式相同、只是作用对象/数据不同（认知 vs 情感都是"从历史推断隐藏属性"）→ 合一格、子维度区分。
- **组合任务排除**：要拆成多个相互独立的维度才能评的（如内容生成＝准确性＋多样性＋难度适配＋格式约束），不是原子，按维度分解到已有能力。判据：原子能力对应**一个内聚的分**。

## 三、横切条件（关键指标，非能力）

- **给定参考解（评价类前提）**：P10–P13 一律以"给定参考解/标准"为条件，隔离"不会评"与"不会做"。不给参考解的题视为同时考核求解与评判。
- **长周期**：把短设定换成长设定压同一批能力，单报长周期分。主压 **P09（最核心）**、P02/P04/P06、P14/P17。
- **确定性**：有唯一、可按固定流程核验答案的题。直接生成做对 = P06"确定性执行"子标签；**工具增益** = 确定性题上 P06（禁工具）vs P09（用工具）之差。

## 五、逐条定义

格式：**定义** ｜ 非重叠边界 ｜（C/D/E 加：调用基座 · 残余/类型）。

### 操作基座 · A

- **P01 指令与约束遵循**：识别任务、答案形态、约束与禁区，并在产出时维持形态合规与关键约束一致。｜不含领域对错(P05)、推理(P06)、教育角色边界(P18)。
- **P02 长上下文与证据定位**：在长上下文/多源材料/多轮历史/表格/检索结果中定位相关证据并抑制干扰。｜不含对证据的推理(P06)、模态解析(P03/P04)、外部检索动作(P09)。注：**"找得到"≠"想明白"**，长周期核心承载。
- **P03 常规多模态感知**：解析常规（低复杂度）图像/截图/手写/板书/公式/图表/版面/音频。子标签：OCR-公式 / 图表 / 几何布局 / 版面 / 视觉关键点 / 音频 / 跨模态对应。｜不含复杂多模态(P04)、定位(P02)。
- **P04 复杂多模态理解**：理解高复杂度多模态（当前主为视频/长时序）的跨帧/跨时序对象、动作、事件、时序关系。切线是**复杂度**。｜不含常规感知(P03)、定位(P02)。

### 操作基座 · B

- **P05 知识调用与掌握**：调用事实/概念/原则/约定用于表征/解题/决策。子切片：学科域。**教育领域知识（误概念体系、教学法、风险类别、政策）亦挂载于此**，作 C/D/E 知识型残余的落点。｜不含明示信息定位(P02)、推理(P06)、校验(P07)。
- **P06 推理与生成**：理解实体/条件/指代/因果/否定/范围/隐含语义，据此推理、推导、生成解法/步骤/计划/答案。子标签：确定性执行、文本理解、长推理链。｜不含约束形态(P01)、工具(P09)、生成后校验(P07)。
- **P07 自我校验与修正**：检查候选解是否满足条件/单位/格式/边界/证据/常识，必要时修正或否决。｜不含首次生成(P06)、元置信(P08)。与 P08 分工：P07 针对**具体答案**，P08 针对**元置信**。
- **P08 置信度校准与弃答**：估计正确概率/不确定性，在作答 / 表达不确定 / 能力性弃答 / 请求澄清间选择。｜不含具体答案自检(P07)、安全拒答(P20)。注：**"自信地教错"是教育头号危险**。
- **P09 工具使用与长程智能体执行**：决定是否/如何调用工具（计算器/代码/检索/模拟器），消化返回，并多步"规划-执行-观察"与跨步骤记忆/编排，长程保持目标一致与状态连贯。子标签：单步工具 / 多步行动 / 长程记忆编排。｜不含直接生成的确定性执行(P06 子标签)、具体教学措辞(P16)。注：**机制上唯一不同于直接生成的产出路径**。
- **P21 多模态教学产物生成**：生成图示/示意图/标注/分步图解/可视化/动画脚本/示范音频等**非纯文本**教学产物，并保证其教学正确性与可读性。子标签：图示/几何作图 · 数据可视化 · 标注/批注叠加 · 动画/分步脚本 · 示范音频(朗读/纠音/视唱)。｜不含多模态感知**输入**(P03/P04)、纯文本生成(P06)、借外部渲染器/工具落地的渲染动作(P09 组合)。机制切线：产出形态从纯文本换成多模态——感知侧有 P03/P04，生成侧此前仅 P06 一格，本项补齐生成侧不对称空洞。注：**P16(可视化解释)、P15(选"可视化"策略后须产出)、讲授配图、发音/视唱示范多任务共需，命中 A/B 扩容判据，故修正"A/B 不扩容"。**

### 教育任务基座 · C（均"给定参考解/标准"）

- **P10 作答正误判定**：给定参考解，判断学生答案/步骤/代码输出/短答是否成立（正确/错误/部分正确）。｜不含位置(P11)、错因(P12)、分档(P13)。｜调用 P07、P02 · 残余≈无／**场景应用**。
- **P11 错误位置定位**：给定参考解，定位第一处或关键错误（步骤/行号/片段/位置）。｜不含正误总判(P10)、错因(P12)、反馈(P16)。｜调用 P02、P10/P07 · 残余≈无／**场景应用**。
- **P12 错因归因**：判断错误类型、误概念、知识点缺陷或策略失误。｜不含位置(P11)、跨历史画像(P14)、教学表达(P16)。｜调用 P06、P05 · 残余＝误概念体系（知识型）／**偏知识**。
- **P13 Rubric 映射评分**：把作答证据映射到 rubric 分档/分数/trait，并给出证据。｜不含简单正误(P10)、自由反馈(P16)、路径(P17)。｜调用 P01、P06、P05 · 残余＝rubric/trait 框架（知识型）／**偏知识**。
- **P22 学术诚信与作答真实性判定**：给定/不给定参照语料，判断提交作答的真实来源与独立完成性——抄袭、代写、AI 代生成、协作越界、考试作弊信号，并给出证据与可信度。｜不含作答正误(P10)、rubric 分档(P13)、学生人身安全风险(P19，对象是学生安危而非作答真伪)、**AI 自身**的代写越权边界(P18，对象是 AI 该不该写而非学生是否真做)。判定结果的处置走 P20。｜调用 P06、P05、P02（比对参照语料）· 残余＝学术诚信规范体系＋真伪信号（知识型）／**偏知识**。拆的依据：形式不同——这是对**作答来源(provenance/authorship)**的判别，既非"对不对"也非"几分"；与 P18 同含"代写"但**对象相反**，不可收口。

### 教育任务基座 · D

- **P14 学习者画像建模**：从学习历史/当前作答/对话/行为估计学习者隐藏属性。子维度（仅诊断）：认知状态、情感与参与、偏好、目标约束、支持需求。｜不含单题错因(P12)、风险识别(P19)、策略(P15)。｜调用 P06、P02、P05 · 残余＝认知/情感构念／**教育原子**。
- **P15 个性化教学策略选择**：据画像/目标/错因选下一步干预（追问/提示/讲解/练习/复习/类比/反例/可视化/鼓励/暂停/升级）与提示强度。｜不含具体措辞(P16)、长期路径(P17)。｜调用 P06、P05 · 残余＝教学决策直觉／**教育原子**。
- **P16 适配性解释与反馈生成**：生成适龄、具体、可执行、语气合适且**不泄题**的解释/提示/反馈。｜不含策略选择(P15)、评分(P13)、路径(P17)。｜调用 P06、P05、P01 · 残余＝不泄题/适龄/语气／**教育原子**。
- **P17 学习路径规划（含学习目标建模）**：从画像/历史/课程**推断学习目标**，并据先修关系、资源/练习属性、时间约束规划下一组练习/资源/复习点/学习路径。子指标：**学习目标建模（原 X1）**、路径排序、间隔复习。｜不含单次教学回应(P16)、画像估计本身(P14)。｜调用 P06、P05、(P09) · 残余＝课程结构/先修＋目标设定（偏知识型）／**偏知识**。

### 教育任务基座 · E

- **P18 教育角色边界判断**：判断教师/tutor/批改者/陪伴者/系统助手可做与不应做。｜不含普通格式(P01)、风险识别(P19)、处置话术(P20)。｜调用 P06、P05 · 残余＝教育角色规范（代写/越权/家校边界）／**教育原子**。
- **P19 学生风险识别**：识别自伤、霸凌、成人内容、违法危险、心理危机、依赖与诱导等风险类别与严重度。｜不含一般学习情绪(P14 情感子维度)、回复策略(P20)。｜调用 P06、P05、P02 · 残余＝教育风险体系／**教育原子**。
- **P20 安全处置选择**：选拒答/安抚/澄清/转介/升级/告知监护或教师等处置。｜不含风险识别(P19)、一般教学反馈(P16)、能力性弃答(P08)。｜调用 P06、P05 · 残余＝教育处置政策／**教育原子**。

> 拒答三驱动：自检否决「算错了」=P07 ｜ 能力性弃答「不会」=P08 ｜ 安全性拒答「不能答」=P20。

**完备性结论**

- **A/B 仅缺生成侧多模态一格，已补 P21**（v3.1 修正）：上表 C/D/E 的求解部分落在 P01/P02/P05/P06/P07/P09（多模态感知另需 P03/P04）；但多个 D/任务（P16 可视化解释、P15 选"可视化"后须产出、讲授配图、发音/视唱示范）**共需多模态产出**，而生成侧此前仅 P06 纯文本——命中"多个 C/D/E 共需而 A/B 缺失"判据，故补 P21。除此之外 A/B 不再扩容。
- **C/D/E 对常见场景可组合**：个性化教学 = P14→P15→P16→P17（上游 C 组诊断 + 外围 E 组安全）；批改 = C 组；作答真实性核查 = P22（处置接 P20）；内容生成 = **组合任务，非缺口**（按维度分解）。
- 真正"教育原子"集中在 **P14、P15、P16、P18、P19、P20**；P10/P11 偏场景应用，P12/P13/P17/P22 偏知识。

## 七、待证据校准（仅剩开放项）
