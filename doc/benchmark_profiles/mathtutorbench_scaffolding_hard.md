# MathTutorBench · Scaffolding (hard)

**一句话**：MathTutorBench 九个子任务之一——脚手架任务的加难版，同样是给出下一句辅导回复，但上下文更棘手。

## 这是哪个子任务

- 家族 MathTutorBench 把辅导拆成九个可分别计分的任务，本页是脚手架的 hard 子集，与常规版分开计分。
- 它属于家族里四个开放式生成任务之一，判分方式是与参考回复比较的胜率。
- 分开计分的初衷是看难度上升后模型是否掉队——实测结果并不支持这个假设，见下方注记。

## 出处与背景

- ETH Zurich LRE 组（Macina 等），2025；https://github.com/eth-lre/mathtutorbench
- 对话数据来自 MathDial，英文。

## 任务与判分

- 给定较难的辅导对话上下文，模型生成下一句回复，与参考回复成对比较取胜率。
- 官方用专家级奖励模型判分，本仓库改用 LLM 裁判做成对判决，绝对分不与论文对照。

## 局限与注意

- 区分度很好：实测均分 2.98、标准差 1.62，与常规版同属全体系拉得最开的一批格子。
- **与常规版的跨模型相关高达 0.98。** 也就是说 hard 变体几乎没有带来新信息，两者本质是同一份证据的两次呈现。做效度检验时不得互为独立证据。
- 分数区间约 1.3–5.6，比常规版整体再低一档。
