# LongTutor · 学生状态诊断

**一句话**：LongTutor 三个子评测之一——从一段长的交互历史里判断这个学生现在的知识状态，四分类。

## 这是哪个子评测

- 家族 LongTutor 面向长程辅导场景，本仓库实现了三个子评测：证据定位、本页的学生状态诊断、以及长历史下的教学动作选择。
- 三者是一条链：先找得到证据，才谈得上判断状态，再谈得上选对动作。本页是中间环节，也是学习者画像能力目前唯一的主证据。
- 与"错因归因"的区别在于时间尺度：归因是从这一次的作答解释这次为什么错，本页是从整段历史判断这个学生整体会什么、不会什么。

## 出处与背景

- 官方仓库只提供 pipeline 脚本，本仓库自行移植为可复现的 adapter，绝对分不与原论文对照。

## 任务与判分

- 给定长交互历史，模型把学生的知识状态归入四类之一，取 macro-F1。
- 取 macro-F1 而非准确率，因为类别分布不平衡。

## 局限与注意

- **分数很低（约 2.0–3.2），这是真实发现不是测量故障**，但要带两条注记读。
- 一是类别不平衡的严重程度：多数类基线的准确率是 0.506，而模型只有 0.35–0.44——也就是说模型的判断还不如"永远猜最常见的那一类"。
- 二是金标的产生方式：由特征决策矩阵加人工修订得到，不是独立盲标，金标本身带有构造痕迹。
- 这一项同时作为错因归因的弱信号计入，但那不是它的主场。
