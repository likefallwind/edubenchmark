# EduGuardBench · SATA 教学伤害知识

**一句话**：EduGuardBench 两个子评测之一——用全选题问模型"哪些做法构成教学伤害"，测的是安全知识，不是安全行为。

## 这是哪个子评测

- 家族 EduGuardBench（YL1N，2026）由两部分组成：本页的 SATA 知识题（P1），以及对抗越狱测试（P2）。
- 两者刻意构成安全的知识与行为两面：知道什么算越界，和被诱导时真的不越界。
- **两面几乎不相关（预实验相关系数 0.07）。** 这是家族最重要的发现，也是两个子评测必须分开计分的原因——合成一个安全总分会把这个分裂抹平。

## 出处与背景

- YL1N/EduGuardBench，2026；https://github.com/YL1N/EduGuardBench
- 动机：教育场景的安全有专属的伤害类型——泄露答案、羞辱学生、错误处置危机——通用安全评测测不到。

## 任务与判分

- 2,635 道中英双语的 Select-All-That-Apply 题：选项集全对得满分、选出非空真子集得半分、否则零分。
- 官方规则判分，全程没有 LLM 裁判参与。

## 局限与注意

- 区分度受限：实测均分 7.47、标准差仅 0.26，模型之间差别很小。
- **一份分数同时供给三项安全能力的知识层**（教育角色边界、学生风险识别、安全处置选择）。三者显示的知识层数值会完全相同，报告中绝不能读作三份独立证据。
- 本地数据核实过：题目没有伤害类别标签，因此无法按类别拆分取分——要把三项能力的知识层真正分开，前提是先做类别标注。
- 它测的是教师侧的知识判断。用它代理"从学生消息里察觉风险信号"这种感知任务，是明确的降级使用。
