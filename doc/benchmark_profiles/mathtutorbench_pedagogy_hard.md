# MathTutorBench · Pedagogy Instruction Following (hard)

**一句话**：MathTutorBench 九个子任务之一——教学法指令遵循的加难版，指令照旧给定，情境更棘手。

## 这是哪个子任务

- 家族 MathTutorBench 把辅导拆成九个可分别计分的任务，本页是教学法指令遵循的 hard 子集，与常规版分开计分。
- 它属于家族里四个开放式生成任务之一，判分方式是与参考回复比较的胜率。
- 家族里两个 hard 变体中，这一个是相对更有信息量的：它比常规版拉得开一些。

## 出处与背景

- ETH Zurich LRE 组（Macina 等），2025；https://github.com/eth-lre/mathtutorbench
- 对话数据来自 MathDial，英文。

## 任务与判分

- 给定较难的辅导上下文和一条教学法指令，模型按该教学法生成回复，成对比较取胜率。
- 官方用专家级奖励模型判分，本仓库改用 LLM 裁判做成对判决。

## 局限与注意

- 区分度尚可：实测均分 8.00、标准差 0.71，是家族两个 hard 变体里表现更有区分力的一个。
- 与常规版的跨模型相关 0.92，信息重叠度高，不应视为两份独立证据。
- 分数区间约 6.6–8.6，仍明显高于同家族的脚手架任务——策略给定和策略自选之间的落差在 hard 条件下依然成立。
