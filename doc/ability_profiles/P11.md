# P11 主观题评价能力

**一句话**：按评分标准给主观作答打分，打得跟有经验的人类评卷人一致。

## 这项能力管什么

- 一篇作文、一道简答题、一段辅导回复——没有标准答案，只有评分标准。模型能不能把作答证据映射到正确的分档，决定了它能不能进批改流程。
- 三种评价操作：给整份作答一个整体分、按步骤或维度拆开逐项判、以及为一个新任务从头写出评分标准。
- 和错误诊断是两件事。诊断是对着参考解找错、解释错；评价是把作答映射到量尺上的分档，机制不同。

## 怎么衡量

- 整体性评分用作文自动评分和简答题总分测，指标是与人类评分的一致性（QWK 类）——不看模型打了几分，看它和人打的分是否同步升降。
- 分析式评分用分步踩分的一致性，以及两套辅导回复的逐维度判卷任务测。判卷任务一律取 macro-F1 而不是裸准确率，因为标签类别高度不平衡，裸准确率会奖励"全猜多数类"。
- 自动生成评分标准这一项目前零覆盖——模型能用 rubric，但能不能造出一份好 rubric，没有测评能回答。

## 读分时注意

- 这里有一个已知的量尺问题，必须说明：判卷任务的 macro-F1（约 3.7–5.6）和整体评分的 QWK（约 7.3–8.7）不在同一个度量尺度上，两者进同一个加权平均隐含了可比性假设。这项能力的分数因此整体下移了约 0.7 到 1.0——那是口径变化，不是模型退步。
- 判卷类证据曾经被整体排除在计分之外，后来重新纳入：对别的能力来说，"模型当裁判打的分"是测量工具而不是被测对象；但对这项能力而言，被测构念恰恰就是判卷能力本身，数据是对口的。
- 子项按评价操作类型划分，而不是按评价对象。"评作文/评简答/评实验报告"这条轴永远列不完，边界判不了。
