# P01 指令与约束遵循

**一句话**：说了就照做——格式、字数、必须包含什么、不许出现什么，这些明写出来的要求能不能稳定执行。

## 这项能力管什么

- 老师要一份"10 道题、每题标难度、不附答案"的练习卷，模型给了 8 道题外加全部答案。内容也许不差，但产物直接返工——这就是这项能力失手的样子。
- 它只问"有没有照做"，不问"做得好不好"。题目质量、讲解水平都是别的能力的事，这里单看约束的执行。
- 它是所有下游功能的地基。凡是把模型接进产品流水线——按模板生成、结构化输出、自动排版——指令一不稳，整条链路就不稳。

## 怎么衡量

- 只用能写成检查函数的约束：字数、关键词、大小写、JSON 格式、段落数。判分不经过 LLM 裁判，没有主观解释空间。
- 取严口径：一条指令里含多个约束，错一个就算不通过。教学产物通常是全或无地可用，不该给"大部分满足"发部分分。
- 这项能力不再拆子项——加约束和守约束是同一件事，按约束类型细分只会把同一个构念切开重算。

## 读分时注意

- 证据只有一个来源，而且是通用指令场景、不是教育场景。分数应读作通用指令遵循的下界参考，不能当成"在教学任务里也这么稳"。
- 曾经把选择题的"格式遵循"和弃答任务的"约束遵循"也算进来，后来摘掉了：前者的分数实际是答对率，知识强的模型会显得更守规矩；后者分不清"守住了约束"和"本来就想弃答"。宁可单源，也不要看起来厚实、实则混着别的能力的证据。
- 各模型分数挤在高位，区分度有限。这是一条门槛——低于线说明有硬问题，分高并不说明更会教。
