# P15 学习路径规划（知识结构层）

**一句话**：知道什么该先学、什么该后学——按知识本身的先修结构排出学习顺序。

## 这项能力管什么

- 要学会解一元二次方程，得先会因式分解；要理解电磁感应，得先有磁通量的概念。这张先修关系网是课程设计的骨架。
- 这项能力只管知识结构这一层：给定一批知识点，判断谁是谁的前置，并排出合理的学习顺序。
- 明确不包括"针对某个学生当前状态的个性化路径"——那是学习者画像和这项能力的组合，不单独设一层。这样划分是为了让"排不好序"和"不了解这个学生"这两种失败可以分开归因。

## 怎么衡量

- 用大规模在线课程知识图谱里的专家标注先修边当金标，测两件事：判断先修关系的选择题、以及把一组知识点排出学习顺序。
- 两者合成一个经过随机基线校正的复合分——不校正的话，二选一任务上"全猜一边"就能拿到看起来不低的分。
- 100% 规则判分，全程没有 LLM 裁判参与。

## 读分时注意

- 分数很低（约 3.8–4.8）。判分方式很硬，所以这个低分不是裁判噪声——模型对知识先修结构的把握确实弱。
- 测试协议是自建的，没有公开基线可以对照，置信上做了折价，请当参考值读。
- 只有一个证据来源。这项能力目前没有跨数据集的互证。
