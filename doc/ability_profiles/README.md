# 原子能力档案

20 项原子能力各一份面向读者的说明：这项能力管什么、失手是什么样、怎么衡量、读分时该注意什么。

用途是展示层——网站的能力详情页从这里取正文。写给的是想理解"这个分数到底在说什么"的读者，不是内部裁决记录。

## 写作约定

- **不写权重数字、不写证据格清单、不写分数占比。** 这些一律由 `data/mapping_measurement_model_v6.json` 生成，网站上单独出表。散文里手写会随下一次裁决静默过期。
- **不写 R 号裁决编号、不写脚本路径和变量名。** 需要交代"曾经这么算、后来改了"时，用自然语言说清楚为什么改，读者不需要知道那次裁决叫什么。
- 具体数字（分数区间、相关系数、区分度）可以写，因为它们是结论的支撑；但要说人话，例如"换三个裁判两两相关不超过 0.14"而不是"judge-swap ρ≤0.14"。
- 每行一条 bullet，自成一句。解析器按 `##` 切小节、按行切 bullet，表格和代码块会被丢弃。
- 一句话摘要写成 `**一句话**：…`，紧跟在标题下。

## 小节模板

- `## 这项能力管什么` —— 从一个具体的失手场景切入，说清构念边界和子项怎么分。
- `## 怎么衡量` —— 测量思路、判分方式、子项各用什么测，以及哪些子项是空白。
- `## 读分时注意` —— 天花板、单源、同源证据、已知缺口、口径变更导致的不可比。

## 事实来源

口径以 `data/mapping_measurement_model_v6.json` 为准，叙述背景见 `doc/atomic_ability_mapping_v6_2026-07-19.md`。两者与本目录不一致时，以 JSON 为准，并回来改这里的文字。
