# P06 推理与生成

**一句话**：一步步把题推对，以及在讲解和归因时把话说得站得住。

## 这项能力管什么

- 两种推理侧重不同：面向标准答案的解题推理，和面向学生的生成式推理——解释一个错误为什么会发生、把一个概念讲到能被追问三层还不塌。
- 解题推理错了，答案就错；生成推理不严谨，答案可能对，但过程里有跳步、有循环论证，学生照着学会学歪。
- 两者不强制协变。竞赛题解得漂亮的模型，讲错因时照样可能给出"因为你粗心了"这种毫无信息量的归因。

## 怎么衡量

- 解题侧用竞赛级和标准化考试的开放题与选择题测，精确匹配判分。
- 生成侧主要看教学场景生成任务里裁判打的推理严密性，辅以纠错任务和错因诊断一致性——后者拿模型给的错因和人工标注的错因比对。
- 通识选择题只作弱信号计入解题侧：它们的分数里知识成分远大于推理成分。

## 读分时注意

- 解题侧分数偏高、区分度有限；生成侧的错因一致性拉得开差距（区间跨度约 3.8 到 6.6），两侧合成后中和了一部分信号。想看真实差异，建议下钻到子项。
- 生成侧的主证据来自 LLM 裁判打分，裁判整体偏宽松、分布压缩。
- 曾经把"先修关系推理"算进来，后来摘除了——那测的是知识结构，不是推理过程。
