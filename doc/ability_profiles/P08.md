# P08 置信度校准与弃答

**一句话**：有多大把握就表现出多大把握，不会的时候直接说不会。

## 这项能力管什么

- 最坏的教育事故不是模型答错，是它用十成的笃定语气答错。学生没有能力分辨，笃定就等于可信。
- 两件相关但可分离的事：一是自信程度和实际正确率对不对得上（校准），二是面对超出能力或根本不可答的问题会不会主动说不会（弃答）。
- 校准是概率质量问题，弃答是行为决策问题。一个模型可以内部概率很准，但被问到就是硬答不肯放弃。

## 怎么衡量

- 两套自建测验按设计各测一半：校准测验看模型的置信表述与实际正确率的一致性，弃答测验看它面对不可答问题的拒答表现，同时惩罚该答不答。
- 弃答分数取平衡口径——只奖励拒答会训练出"什么都不答"的退化策略，必须同时看该答的有没有答。
- 两轮自查测验作为辅助证据计入校准一侧：能发现自己错了和知道自己没把握，共享同一个内核。

## 读分时注意

- 校准分数偏低（约 5.6 到 6.8），弃答分数偏高（约 8.6 到 9.1）。这个反差本身是结论：模型比较愿意在明显不可答时说不会，但在"答得出来、只是可能错"的灰区里仍然表现得过分自信。
- 两套测验都是自建协议、无公开基线，置信上做了折价。
- 弃答测验用的是可判定的不可答问题。真实课堂里的灰区问题（学生问一个超纲但相邻的知识点）没有覆盖到。
