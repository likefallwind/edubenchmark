# P09 工具使用与长程智能体执行

**一句话**：调得动工具、撑得住长任务——这项目前没有任何合适的测评，是明确留白。

## 这项能力管什么

- 教育场景里的智能体形态正在成型：查学情系统、调题库、生成并批改一整套作业、跨周维持一个教学计划。这些都不是单轮问答。
- 拆成两个方向，因为它们会各自独立地失败：一是选对工具、把调用参数构造正确、并且核验工具返回的结果不盲信；二是跨多轮维持计划与状态，中途出错还能恢复。
- 会调工具不代表撑得过长程状态维护，反过来也成立。分开标注比合成一项更能指出该补什么数据。

## 怎么衡量

- 目前无法衡量。教育场景的智能体与工具使用类评测整体缺位，两个方向都是零覆盖。
- 通用领域的智能体评测存在，但没有纳入——它们的任务分布与教育场景相去太远，硬挂上来只会制造一个看起来有分、实则不指向教育能力的数字。

## 读分时注意

- 这项能力在模型排名里不出现分数，报告中标注为"暂未覆盖"。
- 测不了不等于不存在。能力清单按构念本身定义，不随测量可行性伸缩——把它留在清单里，是为了让缺口一直可见。
- 这是当前体系最值得优先补齐的缺口之一，尤其是在教育智能体产品化的节奏下。
