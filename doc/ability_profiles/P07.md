# P07 自我校验与修正

**一句话**：回头复查自己刚写的东西，把错的改对——同时不要把本来对的改错。

## 这项能力管什么

- 模型给学生讲完一道题，再看一遍，能不能自己发现第三步符号搞反了。教学场景里没人替它兜底，自查是最后一道防线。
- 关键是双向的：能改对错的固然好，但把原本正确的答案在"再想想"之后改错，破坏性更大——学生会以为后一版更可信。
- 这项能力和"一开始就答对"是两回事。首轮正确率高的模型不一定复查得好，反过来也成立。

## 怎么衡量

- 主证据是一套自建的两轮自查测验：先让模型作答，再在不给任何提示的情况下要求它复查。核心指标同时看改对率和改错率，各占一半，与首轮正确率解耦。
- 不给提示是关键设计。一旦提示"这里可能有错"，测的就变成了受提示的定位能力，不是自发的复查习惯。
- 辅助证据来自判断给定解法对错的任务，以及置信度校准测验——后者与自查共享"知道自己哪里可能不对"的内核。

## 读分时注意

- 分数普遍偏低（区间约 5.0 到 5.6），这是真实发现不是测量故障：当前模型的自发复查普遍不牢靠，改对的同时也在改错。
- 主证据是自建协议、没有公开基线可以对照，置信上做了折价。横向比较可用，绝对分请谨慎引用。
- 曾经把解题正确率算作辅助证据，后来摘除了——解题强和会复查之间没有构念链。
