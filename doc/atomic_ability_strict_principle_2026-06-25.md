# AI 教育原子能力严格重估：逐条审查与最终口径

日期：2026-06-25

本文接续 `doc/atomic_ability_reassessment_2026-06-25.md`，但采用更严格的 `doc/atomic_principle.md` 口径。结论先说清楚：上一版 A01-A19 仍然不是严格原子能力，很多只是任务簇、模态簇、场景簇或产品能力。本文把它们逐条审查后，压缩为一组更小、更可组合、边界更清楚的最终原子能力候选。

严格意义上，只有完成 item 级模型表现相关性、因子分析和干预实验后，才能说“已验证的原子能力”。本文的“最终”指当前 benchmark 证据下的建模口径：命名和边界尽量满足完备性、最小性、不可再分性、可辨识性和组合性，后续实验只负责验证或微调，而不是继续用 benchmark 场景直接命名能力。

## 判定准则

本轮采用四个操作性规则：

1. 如果两个能力只因输入模态不同而区分，例如图像、视频、课堂监控、手写、图表，先合并为同一能力，模态作为标签。
2. 如果一个能力名称包含具体学科、学段、语言、题型或 benchmark 来源，例如中文 K12、标准化考试、作文、短答案、科学视频，降级为标签。
3. 如果一个能力是产品工作流或复杂任务，例如教学设计、个性化学习方案、课堂分析、交互式科学演示，必须拆成基础能力组合。
4. 如果一个能力内部已经有稳定不同指标，例如角色一致性、攻击失败率、风险转介，不强行合并成一个安全能力。

## 最终原子能力口径

下面 15 项是当前严格版最终口径。它们不是按 benchmark 命名，而是按“复杂教育任务中不可再继续稳定拆分的功能”命名。

| F 码 | 原子能力 | 定义 | 可区分的测量方式 | 常见标签 |
| --- | --- | --- | --- | --- |
| F01 | 概念与规则调用 | 从长期知识或给定材料中调用相关概念、事实、规则、教学法原则，并判断其适用性 | 去掉复杂推理和开放生成，只测概念/规则选择、事实判断、原则适用 | 学科、语言、学段、教师专业、特殊教育 |
| F02 | 输入证据定位与状态表征 | 在文本、图像、表格、视频、代码、课堂片段、学生作答中定位关键证据，并形成可用于后续判断的状态表示 | 控制推理难度，只测证据找对没有；可做遮蔽、无图/有图、无视频/有视频对照 | 文本、图像、图表、手写、视频、音频、代码、课堂 |
| F03 | 约束推理与状态变换 | 根据题干、规则、证据和约束进行多步推理、计算、证明、规划或因果判断 | 给定充分证据后测最终答案、步骤合法性、hard 子集、过程一致性 | 数学、科学、法律、考试、证明、数量、符号 |
| F04 | 受约束产物生成 | 按明确规格生成可检查的外部产物，例如代码、HTML、交互演示、结构化 JSON、公式或可运行脚本 | 程序测试、schema 校验、动作测试、功能通过率；不把视觉美观混进来 | 代码、网页、交互、公式、结构化输出 |
| F05 | 学生作答状态判定 | 判断学生当前答案、步骤、证明、代码或短答是否正确、完整、可接受，必要时给出等级 | 二分类/多分类、步骤正确性、solution correctness；不要求解释错因 | 作文、短答、数学步骤、代码提交 |
| F06 | 错误定位与错因归因 | 在学生作答或互动中定位关键错误位置，并归因为概念误解、策略错误、计算错误、表达问题等 | Mistake Location、错误类型 F1、代码行定位、misconception 标签；不要求生成反馈 | 数学、代码、作文、短答、几何图 |
| F07 | Rubric 评分校准 | 按给定评分标准或专家标注体系稳定给分，并与人工评分保持一致 | QWK、trait agreement、CCS、ECS、分档准确率；可固定内容只比较评分 | 作文、短答、过程评分、课堂评价 |
| F08 | 学习者状态估计 | 根据学习历史、学生画像、行为、对话和作答证据估计隐含学习状态 | KT AUC、概念掌握、参与度、兴趣度、风险、profile alignment；不要求给教学方案 | KT、认知诊断、参与度、画像、学习风险 |
| F09 | 学习目标与知识结构分解 | 把学习目标或知识点拆为先修关系、子目标、关键概念、可评估目标和难度层级 | 给定知识点，评 prerequisite、子目标、知识结构、评价目标；不要求选择讲法或完整教案 | 教案、知识图谱、课程标准、学习目标 |
| F10 | 教学表征选择 | 为某个目标或概念选择合适的例子、反例、类比、图示、板书结构、可视化或演示形式 | 固定学习目标后，评表征是否准确、贴合学生水平、能暴露关键变量；不要求实际生成完整产物 | 例题、类比、图示、可视化、实验、板书 |
| F11 | 教学动作选择与脚手架控制 | 根据学生状态、目标和错误，选择下一步教学动作及支持强度 | 下一步动作分类、Socratic/Scaffolding win rate、是否过早泄题、教学指令遵循 | 追问、提示、讲解、练习、复习、鼓励 |
| F12 | 教学反馈与解释表达 | 在给定诊断和教学动作后，生成学生可理解、可执行、语气合适的反馈或解释 | 固定错因和策略后评清晰度、可操作性、不过度泄题、年龄适配 | 口头反馈、作业批注、代码提示、多轮对话 |
| F13 | 资源与学习路径选择 | 根据目标、先修结构、学习者状态和资源属性选择或排序学习资源与路径 | Recall@k、NDCG、路径连贯性、先修一致性；不把生成学习计划全文算进来 | 课程、视频、题目、讲义、学习路径 |
| F14 | 教育角色边界执行 | 在教师、tutor、批改者、陪伴者等角色中维持专业边界、权限边界和诚实边界 | Role-following score、越权率、作弊协助率、过度承诺率 | 教师角色、家长沟通、考试、批改、陪伴 |
| F15 | 学生风险识别与安全处置 | 识别未成年人风险、心理危机、危险行为、情感依赖、成人内容等，并执行合适拒答、转介或升级 | 风险分类、ASR、安全回复质量、转介质量、年龄适配；对抗提示作为压力测试 | 自伤、霸凌、性风险、违法危险、心理健康 |

## 为什么这 15 项比 A01-A19 更符合原则

### 完备性

当前教育 benchmark 中的主要稳定差异基本可以由这 15 项组合解释：

- 解题类：F01 + F02 + F03。
- 多模态作业反馈：F02 + F05 + F06 + F11 + F12。
- 作文/短答评分：F05 + F06 + F07 + F12。
- 数学/代码 tutor：F01 + F02 + F03 + F05 + F06 + F11 + F12。
- 教案/备课：F01 + F08 + F09 + F10 + F11 + F13。
- 可视化/交互内容：F01 + F03 + F04 + F10 + F12。
- 学情/个性化：F08 + F09 + F11 + F13。
- 课堂分析：F02 + F08 + F11 + F12。
- 安全：F14 + F15。

### 最小性

被删除或降级的内容不是不重要，而是不应作为原子能力：

- A05/A06/A18 的多模态/课堂输入被合并为 F02，模态只作标签。
- A03 被降级为 F03/F05/F07 的过程质量指标。
- A12 被拆成 F09/F10/F11/F12/F13，A17 被拆成 F08/F09/F13。
- A13 被拆成 F04/F10/F12，视觉化只是输出标签。
- D24 被移出原子能力，作为端到端验证层。

### 不可再分性

每项 F 能力仍可能在未来实验中被继续拆分，但目前拆分条件比 A 码严格：

- F05 和 F06 分开，因为“判断学生是否错”和“解释为什么错”可被不同题目区分。
- F09 和 F10 分开，因为“拆学习目标/先修结构”和“选择合适表征方式”可以通过固定目标或固定表征库的任务区分。
- F11 和 F12 分开，因为“选择下一步动作”和“把动作表达成学生能用的反馈”可通过固定诊断/策略的任务区分。
- F14 和 F15 分开，因为角色边界失败和未成年人风险处置失败在 EduGuard/YouthSafe 类任务中可能不是同一模型画像。
- F01 和 F03 分开，因为概念规则调用可以用低推理题测，约束推理可以在给定规则和证据下测。

### 可辨识性

每项能力都能设计近似正交的测量：

- 固定 F01/F02 后测 F03：给出必要公式、图中关键点和规则，只看推理。
- 固定 F09 后测 F10：给定目标结构，只看例子、类比、图示或演示形式选择。
- 固定 F06/F11 后测 F12：给定错因和教学策略，只看反馈表达。
- 固定 F08/F09 后测 F13：给定学生掌握状态和目标结构，只看资源排序。
- 固定 F02 后测 F05/F06：给出学生答案的结构化表示，只看判断和诊断。
- 固定 F14 的角色要求后测 F15：加入具体风险线索，只看风险识别和处置。

### 组合性

复杂教育任务不再直接命名为原子能力：

| 复杂任务 | 组合方式 |
| --- | --- |
| 个性化教学方案 | F08 + F09 + F11 + F12 + F13 + F14/F15 |
| 教学设计 | F01 + F08 + F09 + F10 + F11 + F13 |
| 教学可视化生成 | F01 + F02 + F03 + F04 + F10 + F12 |
| 课堂分析 | F02 + F08 + F11 + F12 |
| 多模态作业反馈 | F02 + F05 + F06 + F11 + F12 |
| 教育安全陪伴 | F08 + F12 + F14 + F15 |

## 还不能宣称完成验证的点

要让 F01-F15 从“原则上更合理”变成“实证上成立”，下一步必须做三件事：

1. 对已有 item 重新打 F 码标签，允许一个 item 有 1 个主 F 码和若干辅助 F 码。
2. 用已跑模型结果检查 F 码间相关性：高度共线的继续合并，内部显著分裂的再拆。
3. 做最小干预实验：固定诊断测反馈，固定学生状态测路径，固定证据测推理，固定角色测风险处置。
