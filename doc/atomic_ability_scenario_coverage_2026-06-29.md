# AI 教育原子能力 · 场景覆盖压力测试（2026-06-29）

目的：把 `atomic_ability_principle_audit_v3.md` 的 **20 项原子能力（P01–P20）** 拿去对**尽可能多的教育场景**做覆盖检验。对每个场景做一次分解：能否由现有能力（含跨层组合）承载？若有**还原不掉的残余**，再判断这个残余是否"值得被单独对待"，从而提出新增原子能力。

**复用 v3 的判定规则（不复述论证）：**
- **拆**：形式/复杂度/机制任一显著不同则拆。
- **收口**：形式相同、只是作用对象/数据不同 → 合一格、子维度区分，**不新增**。
- **组合任务排除**：要拆成多个独立维度才能评的 → 不是原子，分解到已有能力。
- **横切条件 ≠ 能力**：长周期 / 确定性 / 实时性等是关键指标，不是新原子。

**判定符号**：✅ 现有能力可承载（覆盖）｜🟡 现有能力＋收口/组合可承载（伪缺口，给出归并）｜🔴 存在不可还原残余（真缺口，进入第三节）。

## 三、🔴 真缺口：三项不可还原残余 → 候选新增原子能力

三个 🔴（D5/D6、E5、C7/C9）经检验**无法**由现有 20 项组合，且各自对应一个内聚的分，满足"值得被单独对待"门槛。按 v3 格式给出定义。

### P21 多模态教学产物生成（**操作基座新增** · 生成轴）

- **定义**：生成图示 / 示意图 / 标注 / 分步图解 / 可视化 / 动画脚本 / 示范音频等**非纯文本**教学产物，并保证其教学正确性与可读性。
- **非重叠边界**：不含多模态感知**输入**（P03/P04）、不含纯文本生成（P06）、不含借外部渲染器/工具落地的渲染动作（那是 P09 组合）；本项内核是"决定产出何种视觉/多模态结构并保证其内容正确"的产出路径本身。
- **机制切线**：v3 已用"机制不同则拆"分出 P09（工具路径）与 P04（复杂度）。**生成的产出形态从纯文本换成多模态**，是同一逻辑下的又一条机制切线——感知侧有 P03/P04 两格，**生成侧此前只有 P06 纯文本一格，存在不对称空洞**。
- **为何动摇 v3"A/B 不扩容"结论**：v3 §六的不扩容判据是"无多个 C/D/E 共需而 A/B 缺失的基础操作"。但 **P16（可视化解释）、P15（选'可视化'策略后须产出）、讲授配图、B4 纠音/B7 视唱示范** 多个 D/任务**共需**多模态产出，而 A/B 仅有文本生成——恰好命中该判据。故建议**操作基座由 P01–P09 扩为 P01–P09 + P21**。

### P22 学术诚信与作答真实性判定（**C 组评价新增**）

- **定义**：给定/不给定参照语料，判断提交作答的真实来源与独立完成性——抄袭、代写、AI 代生成、协作越界、考试作弊信号，并给出证据与可信度。
- **非重叠边界**：不含作答正误（P10）、不含 rubric 分档（P13）、不含学生人身安全风险（P19，对象是学生安危而非作答真伪）、不含 **AI 自身**的代写越权边界（P18，对象是 AI 该不该写，而非学生是否真做）。
- **残余 / 类型**：学术诚信规范体系 + 真伪信号（知识型，挂 P05）／**偏知识**。调用 P06、P05、P02（比对参照语料）；并对接 E 组（判定后处置走 P20）。
- **拆的依据**：形式不同——这是对**作答来源**的判别（provenance/authorship），既非"对不对"也非"几分"，现有 C 组无此方向，且与 P18 同含"代写"二字但**对象相反**（P18 管 AI，P22 管学生），不可收口。

### P23 群体与协作学习编排（**D 组个性化新增 · 待证据**）

- **定义**：对多学习者群体建模其互动结构 / 分工 / 参与均衡 / 冲突，并据此编排分组、角色分配、协作脚手架、轮转与冲突调解。
- **非重叠边界**：不含单学习者画像（P14）、不含面向个体的策略（P15）。
- **残余 / 类型**：群体动力学与协作教学法（教育原子）。调用 P14（逐个体）、P15、P06。
- **可还原性争议（故标"待证据"）**：可质疑"群体 = N×P14 + P15"。但**涌现属性**（话语权失衡、组内角色互依、协作脚手架、冲突调解）不能由逐个体建模线性叠加得出——这是把"学习者单元"从个人换成群体后产生的不可加残余。建议先作 **P14/P15 的群体子维度**显式评测，若证明逐个体组合接不住涌现项，再升格为独立 P23。（与 v3 §七 F5 多轮一致性同属"先承载、待证据升格"路线。）

## 四、结论与建议

1. **20 项对绝大多数教育场景足够**：~55 场景中，多数 ✅ 直接覆盖，六类 🟡 经收口/组合/横切吸收，**只剩三处不可还原残余**。
2. **三项候选新增**，按确信度排序：
   - **P21 多模态教学产物生成（强，建议直接补）**——唯一**动摇 v3"A/B 不扩容"结论**者：感知侧 P03/P04 双格而生成侧仅 P06 单格，存在结构性不对称，且多 D/任务共需，命中 A/B 扩容判据。
   - **P22 学术诚信 / 真实性判定（中强，建议补入 C 组）**——独立的"来源判别"方向，与 P18 对象相反不可收口。
   - **P23 群体协作编排（中，先作 P14/P15 子维度，待证据升格）**。
3. **建议落地**：
   - 操作基座改写为 **A/B：P01–P09 + P21（生成轴）**，并在 §六完备性结论中把"A/B 不扩容"修正为"A/B 仅缺生成侧多模态一格，已补 P21"。
   - C 组扩为 **P10–P13 + P22**；E 组处置（P20）对接 P22 判定结果。
   - 待证据校准追加：**E7 公平/偏见是否独立维度**、**P23 群体涌现项是否可由 N×P14+P15 还原**——与 v3 §七 既有开放项并列。
4. **收敛性声明**：继续向 AR/VR 嵌入、生理信号、跨机构画像迁移等相邻轴枚举，均回落到既有 P 或上述三残余之一，未再生第四类残余，故判定场景枚举已收敛。
