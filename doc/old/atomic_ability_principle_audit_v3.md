# AI 教育评测原子能力（v3.2·顺序编号版）

日期：2026-07-06

本版采用两层基组与顺序编号：

- **操作基座（A/SRG、B/FDR，P01-P10）**：AI 最小独立操作方向，覆盖指令、感知、定位、知识、推理、校验、弃答、工具执行与多模态产物生成。
- **教育任务基座（C/LAD、D/CLM、E/CEG，P11-P22）**：AI-教育最小独立任务方向，每项 = 若干 A/B 操作组合 + 教育残余。
- **两条规则**：层内非重叠 + 最小；跨层 C/D/E 调用 A/B 是组合，不算重叠。
- **教育残余分流**：残余是领域知识则挂载 P05；残余是不可还原的教育专有操作，则成为该项内核。

## 一、判定门槛

> 一个原子能力 = 一个值得被单独对待的单元：开发值得单独投注意力，评测值得单独给一个分。

- **拆**：形式、复杂度、机制任一显著不同则拆。
- **收口**：多个候选形式相同、只是对象或数据不同，则合一格，用子维度区分。
- **排除组合任务**：需要拆成多个相互独立维度才能评的任务，不作为单一原子能力。

## 二、横切条件

- **给定参考解**：P11-P14 一律以“给定参考解/标准”为条件，隔离“不会评”与“不会做”。
- **长周期**：把短设定换成长设定压同一批能力，主压 P09、P02/P04/P06、P16/P19。
- **确定性**：有唯一、可按固定流程核验答案的题。直接生成做对属于 P06；工具增益由 P06（禁工具）与 P09（用工具）差值体现。

## 四、逐条定义

### 操作基座 A

- **P01 指令与约束遵循**：识别任务、答案形态、约束与禁区，并在产出时维持形态合规与关键约束一致。边界：不含领域对错、推理、教育角色边界。
- **P02 长上下文与证据定位**：在长上下文、多源材料、多轮历史、表格或检索结果中定位相关证据并抑制干扰。边界：不含对证据的推理、模态解析、外部检索动作。
- **P03 常规多模态感知**：解析常规图像、截图、手写、板书、公式、图表、版面、音频等低复杂度多模态输入。边界：不含复杂多模态理解、长上下文定位。
- **P04 复杂多模态理解**：理解视频、长时序、多帧事件和跨模态动态关系。边界：不含常规多模态感知、文本证据定位。

### 操作基座 B

- **P05 知识调用与掌握**：调用事实、概念、规则、学科知识、教学法知识、误概念体系或安全规范。边界：不含明示信息定位、推理、校验。
- **P06 推理与生成**：基于条件、规则、因果、约束和隐含语义进行推理、推导、生成解法、步骤、计划或答案。边界：不含约束形态控制、工具调用、生成后校验。
- **P07 自我校验与修正**：检查候选解是否满足条件、单位、格式、边界、证据和常识，必要时修正或否决。边界：不含首次生成、元置信判断。
- **P08 置信度校准与弃答**：估计正确概率和不确定性，在作答、表达不确定、请求澄清和能力性弃答之间选择。边界：不含具体答案自检、安全拒答。
- **P09 工具使用与长程智能体执行**：决定是否及如何调用检索、代码、计算器、模拟器等工具，消化返回，并维持多步执行的一致性。边界：不含直接生成的确定性执行、具体教学措辞。
- **P10 多模态教学产物生成**：生成图示、示意图、标注、分步图解、可视化、动画脚本、示范音频等非纯文本教学产物，并保证其教学正确性与可读性。边界：不含多模态输入感知、纯文本生成、外部渲染器执行。

### 教育任务基座 C

- **P11 作答正误判定**：给定参考解，判断学生答案、步骤、代码输出或短答是否成立。调用 P07、P02；残余约等于无，属于场景应用。
- **P12 错误位置定位**：给定参考解，定位第一处或关键错误，包括步骤、行号、片段或位置。调用 P02、P11/P07；残余约等于无，属于场景应用。
- **P13 错因归因**：判断错误类型、误概念、知识点缺陷或策略失误。调用 P06、P05；残余为误概念体系，偏知识。
- **P14 Rubric 映射评分**：把作答证据映射到 rubric 分档、分数或 trait，并给出依据。调用 P01、P06、P05；残余为 rubric/trait 框架，偏知识。
- **P15 学术诚信与作答真实性判定**：判断提交作答的真实来源与独立完成性，包括抄袭、代写、AI 代生成、协作越界和考试作弊信号。调用 P06、P05、P02；残余为学术诚信规范体系与真伪信号，偏知识。

### 教育任务基座 D

- **P16 学习者画像建模**：从学习历史、当前作答、对话、行为估计学习者隐藏属性，包括认知状态、情感参与、偏好、目标约束和支持需求。调用 P06、P02、P05；残余为认知/情感构念，属于教育原子。
- **P17 个性化教学策略选择**：根据画像、目标和错因选择下一步干预，包括追问、提示、讲解、练习、复习、类比、反例、可视化、鼓励、暂停或升级。调用 P06、P05；残余为教学决策直觉，属于教育原子。
- **P18 适配性解释与反馈生成**：生成适龄、具体、可执行、语气合适且不泄题的解释、提示或反馈。调用 P06、P05、P01；残余为不泄题、适龄和语气控制，属于教育原子。
- **P19 学习路径规划**：从画像、历史和课程推断学习目标，并依据先修关系、资源属性、练习属性和时间约束规划学习路径。调用 P06、P05、P09；残余为课程结构、先修关系和目标设定，偏知识。

### 教育任务基座 E

- **P20 教育角色边界判断**：判断教师、tutor、批改者、陪伴者或系统助手可做与不应做。调用 P06、P05；残余为教育角色规范，属于教育原子。
- **P21 学生风险识别**：识别自伤、霸凌、成人内容、违法危险、心理危机、依赖与诱导等风险类别与严重度。调用 P06、P05、P02；残余为教育风险体系，属于教育原子。
- **P22 安全处置选择**：选择拒答、安抚、澄清、转介、升级、告知监护或教师等处置。调用 P06、P05；残余为教育处置政策，属于教育原子。

## 六、待证据校准

- **评判 vs 求解隔离**：P11-P14 需要给/不给参考解分测。
- **多轮教学对话管理**：当前由 P06+P09+长周期承载；若证明接不住，再考虑新增能力。
- **难度 / ZPD 适配**：作为 P17 核心子指标，不单独升格。
- **覆盖洼地优先补**：P08、P09、P10、P15、P16 情感子维度、P22。
- **群体协作编排**：暂作 P16/P17 群体子维度承载。
- **公平/偏见/文化敏感**：暂归 P20/P22 政策子维度，是否独立待证据。
