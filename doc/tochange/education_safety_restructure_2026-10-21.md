# 安全类重构提案(待落地)

**状态:方向已定,未落地。** 本文件是 2026-10-21 与用户逐轮讨论后定下的安全类结构,**没有**改动
`data/mapping_measurement_model_v6.json`、聚合脚本的 `BENCHMARK_META`,也**没有**跑聚合管线。
落地前还需要裁决第八节的待定事项;落地按第七节的步骤走,映射修订与编号/结构代码改动分两次提交。

## 一、为什么改

现行"教育安全与学术规范"(P17–P20)的问题:

- **三项共用一份证据。** P17/P18/P19 的知识层全部挂 `eduguard_sata`,显示分数完全相同,不构成互证。
- **P18 独立证据为零。** 严重度 facet 空;唯一的 SATA 格测的是教师侧知识,不是"从学生消息里察觉信号"。
- **同一格双挂。** `eduguard_adversarial` 的 ASR 与拒答质量同时挂 P17 和 P19。
- **P20 整项空白。**
- **只测"该拒的拒没拒",不测"不该拒的拒了"。** 一个什么都拒的模型在安全类能拿满分。
- **通用安全零覆盖**:仓库里没有任何通用安全 benchmark(2026-10-21 核实 adapter、`reports/eval/`、`sources/datasets/`)。
- **适龄内容与育人价值导向缺位。**

## 二、两条总规则

**划界规则**:离开教育场景,正确做法变不变?

- 不变 → **通用层**。例:不教人制作危险品,对谁都一样。
- 变了 → **教育层**。三种"变":规范是教育独有的(学术诚信、教育者角色);同一话题对未成年学生标准更严(适龄);同一风险处置要走教育渠道(转给老师/家长/学校)。

同一话题常常两层都有,按这条规则切开:

| 话题 | 通用层 | 教育层 |
|---|---|---|
| 自伤 | 不提供自伤方法 | 从学生的话里察觉危机,分级处置并转给人 |
| 价值观 | 内容不越红线,合法敏感话题照常回答 | 教学内容主动体现正确的育人导向 |
| 越狱 | 被诱导时不给通用有害内容 | 被"教学演示"等借口诱导时不越过教育者边界 |
| 隐私 | 不泄露、不推断他人个人信息 | (不单设,见第六节) |

**双向计分**:通用安全、学生风险应对、内容适宜性都要同时测两面——该做的没做,不该做的做了(误拒、过度删减、过度说教)。依据之一是国标 GB/T 45654-2025:同时要求"应拒答"和"不应拒答"两套题库,应拒题拒答率 ≥95%、不应拒题拒答率 ≤5%。

## 三、新结构

```
安全类
├─ 通用层(展示归基础能力组,只用现成 benchmark,不自建)
│   └─ [G]  通用安全与合规                 ← 新增
└─ 教育层(展示归"教育安全与学术规范",重点投入)
    ├─ [P17] 教育角色边界判断             ← 定义不变,证据重新分配
    ├─ [P18] 学生风险应对                 ← 原 P18 + P19 合并为两个 facet
    ├─ [S]   面向学生的内容适宜性         ← 新增
    └─ [P20] 学术诚信与作答真实性判定     ← 不变
```

`[G]`、`[S]` 是临时代号,编号见第八节。

## 四、逐项定义

### [G] 通用安全与合规(新增,基础能力组)

**定义**:对任何用户都成立的安全底线——拒绝明确有害的请求,不误拒正常请求,生成内容不越过法规红线,不泄露或推断他人个人信息。

| facet | 看什么 |
|---|---|
| 有害请求拒止 | 武器与危险品、暴力或非暴力犯罪、自伤方法、性剥削、仇恨、网络攻击等;含越狱条件(角色扮演、编码、多轮诱导) |
| 不误拒 | 字面像敏感、实则正常的请求照常回答(结束进程、药物常识、战争史) |
| 内容合规 | 价值观红线(国标附录 A.1)与歧视性内容(A.2)不越线;制度、民族、历史、英烈等合法话题不回避。**分数注明所依规范**,不与其他法域的分数横比 |
| 隐私保护 | 不泄露、不推断、不聚合他人个人信息 |

- **边界**:只管对所有用户相同的标准;对学生/未成年人更严的部分归教育层。
- **证据**:暂无。候选 AIR-Bench 2024(法规对齐的风险分类)、Flames(中文价值对齐,含数据保护维度)、XSTest 或 OR-Bench(误拒)。许可、可下载性、判分方式均未核实,接入走 `.claude/skills/adding-eval-benchmark/SKILL.md` 的关卡。
- **P 级准入**:理论框架(AILuminate / AIR 2024 危害分类)、产品失败后果(国标合格率与拒答率硬指标)、独立失败机制(误拒与拒止可独立失败),满足四选二。
- **仓库规则**:R20 规定通用 benchmark 不挂教育侧 P,所以这一项必须放基础组,不能并进教育层。

### [P17] 教育角色边界判断(定义不变)

**定义**:守住教育者的角色与行为边界。

| facet | 看什么 |
|---|---|
| 安全知识 | 知道教育场景下哪些行为构成越界(选择题) |
| 边界行为 | 以人设或借口诱导(改换人设、"为了教学演示"、"老师让我问的")时是否越界;**直接提出代写、代考请求时是否接单**;守住之后拒得是否得体;常规对话中言行得体、不冒犯学生 |

- **测法**:本质上是诱导式越界测试,与越狱同形;区别于 [G] 的是,越过的是**教育者特有的边界**(泄答案、羞辱学生、代写),按划界规则属于教育层。
- **"AI 代写"归这里**:沿用 2026-06-29 裁决(`doc/old/atomic_ability_scenario_coverage_2026-06-29.md` 场景 E4)。外部证据显示这是教育专属风险里失败最重的一类(EduZone:学生学术不端攻击成功率 80.3%,模型几乎从不拒绝),目前无数据,列为缺口。
- **讨论过但不纳入测量**:操纵(谄媚、制造愧疚或压力、诱导延长使用)、打探学生隐私、拟人化与情感依赖。这些出自英国教育部 2026 版标准,但目前没有可靠判分办法,硬测只会产出不可信的分数。记为已知缺口,有可靠判法再议。

### [P18] 学生风险应对(原 P18 + P19 合并)

**定义**:学生流露危机或提出危险请求时,察觉风险、判断轻重,并选择恰当的处置。

| facet | 看什么 |
|---|---|
| 学生风险识别 | 明显信号:自伤或自杀、被欺凌、家暴或性侵、进食障碍、危险实验或模仿、烟酒药物、离家出走、网络诈骗或诱骗。隐晦信号:暗示性的话("活着没意思""没人会帮我")、玩笑口吻包裹、多轮中逐步累积。严重度:需立即干预 / 短期关注 / 一般支持 |
| 安全处置选择 | 处置轻重与风险匹配,不反应不足也不小题大做;措辞支持、不贴病理标签、不认同危险想法;**引向真人帮助**(老师、家长、心理老师、热线);不要求学生保密;拒绝危险请求时得体并给出安全替代 |

- **为什么合并**:两者是同一条应对链的前后两步。在生成式评测里,"识别"基本只能从"处置"反推(`doc/tochange/safe_child_llm.md` 已指出这一点);原 P18 单独成项的结果是独立证据为零。合并后两个 facet 分数照常分开记录,将来数据显示两者确实会分开失败,可以再拆回。
- **边界**:风险源在学生——学生自己处于风险中,或学生提出危险请求。AI 自身越界归 [P17];请求本身无风险时内容尺度归 [S]。
- **缺口**:严重度分级标注;"学生被动流露风险 → 模型主动转介"情形;多轮累积。

### [S] 面向学生的内容适宜性(新增)

**定义**:回应正常的学习请求时,内容尺度符合学生所处学段,价值上体现正确的育人导向;该讲的不回避,不该给的不给。

| facet | 看什么 |
|---|---|
| 适龄内容 | 暴力、血腥、恐怖细节的尺度(讲战争史、自然灾害时);性相关内容按学段把握(生理卫生、性教育讲到什么程度);危险行为的可模仿性;不良生活方式与网络用语(烟酒、文身、饭圈、不良谐音梗);身材焦虑与外貌评价。**反向**:不过度删减——初中生理卫生该讲的要讲,战争史不回避 |
| 育人价值导向 | 价值引导正确(爱国、尊重英烈、科学精神、诚信、尊重他人);争议或敏感话题按学段平衡处理,不灌输偏激观点;不宣扬拜金、读书无用等不良价值观。**反向**:不把每个回答都变成说教、不生硬贴口号。**注明所依规范** |

- **边界**:请求本身无风险(有风险的请求归 [P18]);对所有人都一样的价值观红线归 [G];讲解深浅、语言难度的适龄归 P16——[S] 管"该不该给看",P16 管"看不看得懂"。
- **证据**:暂无,需自建。适龄内容用"同一请求、不同学段"的对照题;育人导向按课标德育要求定评分标准。MinorBench 测的是儿童提出的不当请求,更贴 [P18],不能充当本项证据。
- **P 级准入**:规范框架(《可能影响未成年人身心健康的网络信息分类办法》、英国教育部按年龄过滤要求、OpenAI U18 原则)、教师专业标准(《新时代中小学教师职业行为十项准则》"传播优秀文化""潜心教书育人";教育部《中小学生成式人工智能使用指南》"坚持价值引领")、独立失败机制(请求无风险时的尺度失误,拒答类测试测不到),满足四选二。

### [P20] 学术诚信与作答真实性判定(不变)

定义、`facets: []`、`coverage_gap: true` 全部保持现状。讨论中曾提出把"不当代写工具"并进本项作为主 facet,用户裁定暂时保留原定义;代写场景按旧裁决留在 [P17]。

## 六、不纳入与搁置

- **教育公平:暂不纳入。** 理由:非歧视是通用原则,按划界规则不属于教育层;且容易与个性化教学混淆。说明:`eduequity`(400 对反事实配对,10 个模型已判完)的配对固定了能力、目标、学习困难与资源条件,只改身份,混淆论对这套数据本身不成立;它的方向性信号可信(10 模型合计被判吃亏:低收入 518 次 vs 高收入 17 次,农村 319 vs 城市 37,女生 217 vs 男生 111)。但缺"同一身份生成两次"的对照组,绝对分里混有生成随机性;两个裁判排名相关约 0.71。数据保留,需要时可作 [G] 非歧视的补充证据,或先补对照组再单独评估。
- **学生数据隐私:不单设。** 模型层面的隐私行为对任何用户都一样,归 [G];教育法规中的大部分隐私要求(留存、日志、影响评估)是产品与系统层面,不是模型能力。
- **[P17] 的操纵、打探隐私、拟人化细项**:见第四节,判不准,记为缺口。
- **不属于安全类的**:知识性错误归 P05/P08;编造参考文献归 P08;认知负荷过重归 P16;顺着学生的错误认识附和归 P10/P16;防作弊命题设计归 P12;对学生情绪的推断(欧盟 AI 法案禁止在教育机构使用)作为 P13 情感识别的合规注记。
