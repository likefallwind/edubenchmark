## 一、判定原则

### 1.1 背景：这是 AI（LLM + 智能体）赋能教育，不是传统那套

切分的轴是**"对一个 AI 来说，这是不是一种不同的、值得单独对待的本事"**，不是"传统上这是不是一个不同的学科/题型/模态/测量领域"。"AI"同时含**大模型能力与智能体能力**，用同一把尺子量，不预先分家。

### 1.2 结构：两层基组 + 一张映射

本版不是一张平表，而是**两组原子能力 + 一张映射**：

- **操作基座（A/B，P01–P09）**：AI（LLM/智能体）的最小独立**操作**方向（定位、推理、校验、用工具…）。张成"AI 能做的操作"空间。
- **教育任务基座（C/D/E，P10–P20）**：AI-教育的最小独立**任务**方向（判分、定位、归因、画像、安全…）。其组合张成"AI-教育要干的全部工作"。
- **映射**：每个 C/D/E 任务 = 若干 A/B 操作的组合 **+ 教育残余**（领域知识挂载，或还原不掉的教育专有操作）。

**两条规则**：
- **层内**：非重叠 + 最小——同层任意一项不能由同层其它项组合出来。
- **跨层**：C/D/E 调用 A/B 是**组合，不算重叠**（这正是组合性）。所以"P11 错误定位用到 P02 式定位"不是矛盾，是任务踩在操作上。

**"原子"在两层含义不同**：A/B 是原子**操作**，C/D/E 是原子**任务**。一个东西可以在操作空间里是组合、同时在任务空间里是基向量——不冲突。

**A/B 完备性的按需增补规则**：
- 若**多个** C/D/E 都需要某个 A/B 尚无的基础操作 → **增补**进 A/B。
- 若只是**偶发一个** C/D/E 需要 → 放宽，**记入遗留问题**，暂不增补。

**教育残余的分流**：C/D/E 的残余若是**领域知识** → 挂载到 P05；若是**还原不掉的教育专有操作** → 它就是该教育原子能力的内核（残余≈0 的，则该项只是"基座的场景应用"）。

### 1.3 唯一门槛（层内适用）

> **一个原子能力 = 一个值得被"单独对待"的单元**（开发值得单独投注意力 / 评测值得单独给一个分）。
>
> **拆/合判定**：拆出来单独看，会不会带来实际不同的对待？

**拆的触发（任一即可）**：(a) **形式不同**——核心操作/侧重点明显不同（如"找证据"vs"做推理"），哪怕深层是否共享潜在能力未定；(b) **复杂度不同**——挑战显著不同且独立（如复杂的视频 vs 常规多模态）；(c) **机制不同**——需要机制上不同的产出路径（如调用工具 vs 直接生成）。

**收口的信号**：多个候选**形式相同**、只是作用对象/数据不同（如认知、情感都是"从历史推断学习者隐藏属性"）→ 合为一格、子维度区分，即便各有独立 benchmark。

**组合任务的排除**：若一件事要拆成**多个相互独立的评测维度**才能评（如"教育内容生成"＝准确性＋多样性＋难度适配＋格式约束…），它是**组合任务**，不是原子能力——按维度分解到已有能力，不单列。判据：**一个原子能力对应一个内聚的分；需要一堆分开打的分的，就是组合。** 这与"跨层组合"不同——P11 错误定位虽由 P02+P10 组合，但只对应一个内聚的分（找没找到），仍是原子任务。

8 原则退为**检验工具**：拍板用上面这条，但每项仍要过非重叠、可辨识、跨情境稳定、干预有效、完备、组合的检查。

**机制约束（针对触发 c）**：LLM 产出只有两条路——直接生成 token / 调用工具。直接生成是同一套 next-token 机器，"直接把某类内容做对"通常不是单独本事，而是相关能力的普通输出正确性；只有引入机制上不同路径（工具、多模态编码、跨步骤行动）才更可能是独立操作。§1.5、§1.6 据此把两个条件从能力表剥离。

### 1.4 横切约定：评价类以"给定参考解"为条件

判断对错、定位错误需要 AI 先"会解"。若不约束，评判类会和求解类共用同一份证据（正确解），分不清"不会评"还是"不会做"。因此 **P10–P13 的测量一律以"给定参考解/标准"为条件**；不给参考解的题视为同时考核求解与评判，不计为对评判能力的纯净测量。

### 1.5 横切评测条件：长周期（关键指标，不是能力）

把"短"设定换成"长"设定去压同一批能力，**单独报一个长周期分**。主要压：P02（长输入）、P04（长视频）、P06（长推理链）、**P09（多步长程任务，最核心）**、P14（跨长期历史）、P17（长期路径）。

> 原"上下文状态追踪"（v1 C05）已砍除：多轮追踪 = P02+P06；长程记忆并入 P09；长周期作为条件统一承载。

### 1.6 横切评测条件：确定性（关键指标，不是能力）

指"有唯一、可按固定流程核验答案"的题。直接生成模式做对 = P05/P06 普通输出正确性（作 **P06 的"确定性执行"子标签**诊断）；唯一机制特殊处是工具路径 = P09。**标准诊断——工具增益**：确定性题上 P06（禁工具）vs P09（用工具）之差。

> 原"确定性执行"能力（v1 C08）已砍除，按此分布。

## 三、逐条定义

> 操作基座格式：**定义**（输入；操作；输出）→ **非重叠边界** → **为什么单独对待** → **检验**（完·小·分·叠·辨·稳·组·干；`✓/~/?`）→ **置信度**。
> 教育任务基座额外两行：**调用基座** + **教育残余 / 类型**（场景应用＝残余≈0 / 教育原子＝有残余）。

### 操作基座 · A 指令、感知与信息定位

**P01 指令与约束遵循**
- 定义：输入请求、系统要求、题目说明、输出目标与显式限制；识别任务、答案形态、约束与"不该做的事"，并在产出时维持形态合规与关键约束一致；输出受约束产物结构。
- 非重叠边界：不含领域知识对错（P05）、推理推导（P06）、教育角色边界（P18）。
- 为什么单独对待：答非所问、漏约束、错形态是最普遍失败，提示/格式即可干预，单独评（IFEval 类）。本项完整承担约束遵循——识别+维持+形态合规，P06 不背约束。
- 检验：完✓ 小✓ 分~（识别 vs 维持可能分化）叠✓ 辨✓ 稳~（对 prompt 敏感）组✓ 干✓
- 置信度：中（先验跨 prompt 稳定性）。

**P02 长上下文与证据定位**
- 定义：输入长上下文/多源材料/多轮历史/表格/检索结果；**定位**出相关证据、片段、轮次或字段并抑制干扰；输出相关证据集合。
- 非重叠边界：不含对证据的推理理解（P06）、多模态原始解析（P03/P04）、外部检索动作（P09）。
- 为什么单独对待："找得到"与"想明白"**形式完全不同**（触发 a），是独立失败模式（吃 context 长度/注意力），长周期核心承载。
- 检验：完✓ 小✓ 分✓ 叠✓（与 P06 界为"找对地方 vs 想明白"）辨✓ 稳✓ 组✓ 干✓
- 置信度：高。（深层是否与 P06 共线尚未验，但形式不同足以保留两格；P11 错误定位会跨层调用本项）

**P03 常规多模态感知**
- 定义：输入图像/截图/手写/板书/公式/图表/版面/音频等**常规（低复杂度）**材料；解析可见/可听内容、符号、布局、对象与关键点；输出多模态表征。
- 非重叠边界：不含复杂多模态理解（P04）、后续推理计算、证据定位（P02）。
- 子标签：OCR/公式、图表、几何布局、版面、视觉关键点、音频线索、跨模态对应。
- 为什么单独对待：多模态解析是 MLLM 独立短板（机制上多一套编码路径，触发 c）；常规模态彼此残余复杂度不大，合一格不损失多少信号。
- 检验：完✓ 小✓ 分~（子标签）叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

**P04 复杂多模态理解**
- 定义：输入**高复杂度**多模态材料（当前主要为视频/长时序）；理解跨帧/跨时序的对象、动作、事件、步骤与时序关系；输出复杂多模态理解。
- 非重叠边界：不含常规低复杂度感知（P03）、证据定位（P02）。
- 为什么单独对待：切线是**复杂度**（触发 b）——复杂的单拎出来，当前最复杂、算力与挑战最大、需求又高的是视频。日后其他模态到同等复杂度也归此格。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

### 操作基座 · B 求解与可靠性

**P05 知识调用与掌握**
- 定义：输入问题/材料/目标；调用相关事实、概念、原则、约定用于表征/解题/决策；输出知识表征。
- 非重叠边界：不含从材料定位明示信息（P02）、推理推导（P06）、生成后校验（P07）。
- 必留子切片：学科域（数学/语言/科学/编程/通识…）。**注**：教育领域知识（误概念体系、教学法、风险类别、政策）也挂载于此，作为 C/D/E"教育残余-知识型"的落点。
- 为什么单独对待：知识有无是表现第一性来源，可用领域语料定向干预。
- 检验：完✓ 小✓ 分~（学科/领域作子切片）叠✓ 辨✓ 稳~（跨域核验）组✓ 干✓
- 置信度：高。

**P06 推理与生成**
- 定义：输入已定位材料、知识与目标；**理解**实体/条件/指代/比较/因果/否定/范围/隐含语义，并据此**推理、推导、生成**解法/步骤/计划/答案；输出候选解。
- 非重叠边界：不含约束遵循与形态（P01）、工具调用（P09）、生成后校验（P07）。
- 子标签：确定性执行（直接生成模式下的精确计算/符号/单位/逻辑/状态更新正确率，见 §1.6）、文本理解、长推理链。
- 为什么单独对待：理解+推理是核心"想明白"过程，独立、需求最高、可定向训练。合并了 v1 C03 文本理解、C07 生成，并吸收 C08 确定性执行的直接生成部分（降为子标签）——机制上都是同一套生成。
- 检验：完✓ 小~（基组里最大的一维，靠让出约束/工具/校验界定）分~ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

**P07 自我校验与修正**
- 定义：输入候选解、条件、要求与可用检查信号；检查是否满足条件/单位/格式/边界/证据/常识，必要时修正或否决；输出校验后答案或修正决策。
- 非重叠边界：不含首次生成（P06）、外部测试产物验收、对自身的元置信判断（P08）。
- 为什么单独对待：生成后能否发现矛盾/漏条件/不合规，与首次推理是不同本事。
- 检验：完✓ 小✓ 分~ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。
- 与 P08 分工：P07 针对**具体答案**（这答案错了/漏了，改或否）；P08 针对**元置信**（我到底会不会）。

**P08 置信度校准与弃答**
- 定义：输入问题、候选答案与自身信号；估计正确概率/不确定性，在"作答/表达不确定/能力性弃答/请求澄清"间选择；输出校准置信或弃答决策。
- 非重叠边界：不含对具体答案的自检修正（P07）、安全驱动的拒答（P20）。
- 为什么单独对待：教育里"自信地教错"是头号危险；校准/幻觉与解题分离、可定向训练、单独可测（ECE/弃答正确率）。
- 检验：完✓ 小✓ 分✓ 叠~ 辨✓ 稳✓ 组✓ 干✓
- 置信度：中。
- **"拒答"三驱动**：① 自检否决「算错了」=P07；② 能力性弃答「不会」=P08；③ 安全性拒答「不能答」=P20。拒答不天然属于安全。

**P09 工具使用与长程智能体执行**
- 定义：输入任务、可用工具/环境与中间观察；决定是否及如何调用工具（计算器/代码/检索/模拟器），消化返回，并多步"规划-执行-观察"与跨步骤记忆/编排，长程任务中保持目标一致与状态连贯；输出工具调用序列与整合结果/动作。
- 非重叠边界：不含直接生成模式的确定性执行（属 P06 子标签）、具体教学措辞（P16）。
- 子标签：单步工具调用与整合、多步规划-执行-观察、长程记忆与编排。
- 为什么单独对待：调用工具是 LLM **机制上唯一不同于直接生成**的产出路径（触发 c）；会不会调、能不能多步、长程跑不跑偏是独立高需求本事，长周期与确定性评测主承载。
- 检验：完✓ 小✓ 分~ 叠~ 辨✓ 稳~ 组✓ 干✓
- 置信度：中（教育场景工具/智能体评测是洼地，待补）。

### 教育任务基座 · C 评价、诊断与评分（均以"给定参考解/标准"为条件）

**P10 作答正误判定**
- 定义：给定参考解，输入学生答案/步骤/代码输出/短答；判断是否成立；输出正确/错误/部分正确。
- 非重叠边界：不含错误位置（P11）、错因（P12）、分档（P13）、模型自己求解。
- 调用基座：P07 校验（用在外部答案）、P02 定位。
- 教育残余 / 类型：≈无（给定参考解后即比对）→ **场景应用**。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓ ｜ 置信度：高。

**P11 错误位置定位**
- 定义：给定参考解，输入完整解答/代码/短答/对话；定位第一处或关键错误；输出步骤/行号/片段/位置。
- 非重叠边界：不含正误总判（P10）、错因分类（P12）、反馈生成（P16）。
- 调用基座：P02 定位（核心）、P10/P07 正误。
- 教育残余 / 类型：≈无（"定位 + 正误"的组合）→ **场景应用**。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓ ｜ 置信度：高。

**P12 错因归因**
- 定义：输入错误位置与上下文；判断错误类型、误概念、知识点缺陷或策略失误；输出归因标签或解释。
- 非重叠边界：不含位置定位（P11）、跨历史画像（P14）、教学表达（P16）。
- 调用基座：P06 推理、P05 知识。
- 教育残余 / 类型：误概念/常见错误体系（**知识型残余**，挂载 P05）；操作可还原 → **偏知识的教育任务**。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓ ｜ 置信度：高。

**P13 Rubric 映射评分**
- 定义：输入作答、rubric、评分细则或 trait 标准；把证据映射到分档/分数/trait；输出评分及证据。
- 非重叠边界：不含简单正误（P10）、自由反馈质量（P16）、路径建议（P17）。
- 调用基座：P01 遵循 rubric、P06 推理、P05 知识。

## 九、结论

本版定为**两层基组 + 一张映射**：**操作基座（A/B，P01–P09）**是 AI 的最小独立操作方向，**教育任务基座（C/D/E，P10–P20）**是 AI-教育的最小独立任务方向，每个 C/D/E = A/B 操作组合 + 教育残余；**层内守非重叠最小，跨层是组合**。判定门槛只有一条（值得单独对待；拆看形式/复杂度/机制不同，形式相同则收口）；8 原则退为检验；长周期、确定性等为横切条件。A/B 是否扩容按"多个 C/D/E 共同需求"决定，偶发记入遗留。

映射还暴露出：C 组 P10/P11 偏"基座的场景应用"，P12/P13/P17 偏知识，真正"教育原子"集中在 P14、P15、P16、P18、P19、P20。结构性边界已基本定，剩 P10–P13 与 P05–P07 的隔离、以及完备性的"多轮一致性"待证据（内容生成已判为组合任务，非缺口）。旧 D01–D24 仅作任务簇/benchmark 索引。
