## 一、判定一个原子能力的唯一门槛

### 1.1 背景：这是 AI（LLM + 智能体）赋能教育，不是传统那套

切分的轴是**"对一个 AI 来说，这是不是一种不同的、值得单独对待的本事"**，而不是"传统上这是不是一个不同的学科 / 题型 / 模态 / 测量领域"。

"AI"在这里**同时包含大模型能力和智能体能力**，用**同一把尺子**去量，不预先分"这是 LLM 的还是 agent 的"再特殊处理。

### 1.2 目的

找出一组 AI-教育原子能力，使得**它们的组合 = ai-edu 所需的一切**。这是一个"基组（basis）"：每一项是 AI-能力空间里的一个独立方向，组合起来张成整个教育所需的能力空间。

### 1.3 唯一门槛

> **一个原子能力 = 一个值得被"单独对待"的 AI 能力单元。**
>
> "单独对待"有两个落点：开发模型时值得为它单独投入注意力；做评测时值得为它单独给一个分。
>
> **拆/合判定**：把它拆出来单独看，**会不会带来实际不同的对待**？
> - **会 → 拆。** 常见触发理由（任一即可）：**挑战大且独立** / **需求大** / **需要一套明显不同的本事**。
> - **不会 → 合并。** 拆出来也不改变你怎么开发、怎么评，那它就搭车在邻居身上，作为子标签，不单独占一格。

"挑战大"只是触发"需要单独对待"的一个例子，不是门槛本身。门槛带主观性，是设计决策不是发现的真理；因此 8 条原则退居为**检验工具**：拍板拆不拆用上面这一条，但每项仍要过非重叠、可辨识、跨情境稳定、干预有效、完备、组合的检查，防止自欺。

**机制约束（重要）**：一个 LLM 产出任何东西只有两条路——**直接生成 token** 或 **调用工具**。直接生成用的是同一套 next-token 机器，所以"直接把某类内容做对"通常不是一种单独的本事，而是相关能力（知识/推理）的普通输出正确性；只有当某件事引入了**机制上不同的路径**（如外部工具、多模态编码、跨步骤行动）时，才更可能是一种独立能力。下面 §1.5、§1.6 的两个"横切条件"正是据此从能力表里剥离出来的。

### 1.4 横切约定：评价类以"给定参考解"为条件

判断学生作答对错、定位错误，需要 AI 先"会解"。若不约束，评判类能力会和求解类能力共用同一份证据（正确解），就分不清"它不会评"还是"它不会做"。因此 **P10–P13（评价/诊断/评分）的测量一律以"给定/已知参考解或评分标准"为条件**；不给参考解的题视为同时考核求解与评判，不计为对评判能力的纯净测量。

### 1.5 横切评测条件：长周期（关键指标，不是能力）

**长周期不是一种原子能力，而是一个横切的评测条件 / 关键指标**，与难度、语言、模态、题型并列。它把"短"的设定换成"长"的设定，去压同一批能力，并**单独报一个长周期分**。它主要压：

- P02 长上下文与证据定位（长输入）
- P04 视频与长时序多模态理解（长视频）
- P06 推理与生成（长推理链）
- **P09 工具使用与长程智能体执行（多步长程任务）—— 最核心的承载**
- P14 学习者认知状态建模（跨长期历史）
- P18 学习路径规划（长期路径与节奏）

> 原先设想的"上下文状态追踪"能力（v1 C05）已**砍除**：它的多轮追踪 = P02 定位 + P06 推理在多轮设定下的表现；它的长程记忆并入 P09；长周期作为条件统一承载，不再单列为能力。

### 1.6 横切评测条件：确定性（关键指标，不是能力）

**确定性也是一个横切评测条件 / 任务属性，不是能力**。它指"这道题有唯一的、可按固定流程核验的答案"（算术、符号变换、单位换算、逻辑式求值、可判定状态更新等）。按 §1.3 的机制约束：

- **直接生成模式下把确定性题做对 = P05/P06 的普通输出正确性**（尤其 P06 推理与生成）。它没有独立的"计算引擎"，和回忆事实、写推理是同一套机器，因此**不单列为能力**，只作 **P06 的"确定性执行"子标签**做诊断。
- **唯一机制上特殊的是工具路径 = P09**。这才是确定性问题里真正不同的一种本事。
- **标准诊断——工具增益**：在确定性题上比较 **P06（禁工具直算）vs P09（用工具）** 的差，直接量化"挂工具有多大用"。

> 原 v2 的"确定性执行"能力（v1 C08）已**砍除**：直接模式归 P06 子标签，工具模式归 P09，确定性本身降为横切条件。

### 1.7 两层只为定位覆盖洼地，不表示重要性

P01–P09 偏**通用 AI 底座**（不会解、不会用工具就谈不上教），P10–P21 偏**教育特异**，是核心教学能力，也是 benchmark 覆盖最薄的地方。分层只用于解释"哪里缺评测"。

## 三、逐条定义

> 每项格式：**定义**（输入；操作；输出）→ **非重叠边界** → **为什么值得单独对待** → **8 原则检验**（符号 `✓` 有支撑 / `~` 有风险待验 / `?` 证据不足；字段 完·小·分·叠·辨·稳·组·干）→ **置信度**。

### A. 指令、感知与信息定位

**P01 指令与约束遵循**
- 定义：输入用户请求、系统要求、题目说明、输出目标与显式限制；识别要完成的任务、答案形态、约束与"不该做的事"，并在产出时保持输出形态合规、关键约束一致；输出符合要求的受约束产物结构。
- 非重叠边界：不含领域知识对错（P05）、不含推理推导本身（P06）、不含教育角色/伦理边界（P19）。
- 为什么单独对待：答非所问、漏约束、错输出形态是 AI 最普遍的失败；提示/格式干预即能改变，开发与评测都要单独盯（IFEval 类）。**本项完整承担"约束遵循"——识别约束 + 生成时维持约束 + 输出形态合规——P06 不再背约束。**
- 检验：完✓ 小✓ 分~（识别约束 vs 维持约束可能分化，留子标签）叠✓ 辨✓ 稳~（对 prompt 格式敏感，首要验证项）组✓ 干✓
- 置信度：中（须先验证跨 prompt 稳定性）。

**P02 长上下文与证据定位**
- 定义：输入长上下文、多段材料、多轮历史、表格或检索结果；在大量/多源材料中**定位**出与当前任务相关的证据、片段、轮次或字段，并抑制干扰；输出相关证据集合。
- 非重叠边界：不含对证据语义的推理理解（P06，已收归 P06）、不含多模态原始解析（P03/P04）、不含外部检索动作（P09）。
- 为什么单独对待：长上下文里"**找得到**那条关键信息"是独立失败模式（吃 context 长度/注意力），与"想明白"是两回事，是长周期评测的核心承载之一。
- 检验：完✓ 小✓ 分✓ 叠✓（与 P06 界为"找对地方 vs 想明白"）辨✓ 稳✓ 组✓ 干✓
- 置信度：高。（收窄后比 v1 的 C02/C03 更干净：原"理解语义"半已移入 P06）

**P03 常规多模态感知**
- 定义：输入图像、截图、手写、板书、公式图片、图表、版面、音频等**常规**多模态材料；解析其中可见/可听的内容、符号、布局、对象与关键点；输出多模态表征。
- 非重叠边界：不含视频/长时序理解（P04）、不含后续领域推理与计算、不含证据定位（P02）。
- 子标签（仅诊断）：OCR/公式转写、图表读取、几何布局、版面结构、视觉关键点、音频线索、跨模态对应。
- 为什么单独对待：多模态输入解析是 MLLM 的独立短板（机制上多了一套编码路径），教育里图文题、板书、批改截图需求极大；但常规模态彼此残余独立难度不大，合为一格不损失多少评测信号。
- 检验：完✓ 小✓ 分~（OCR/图表/音频留子标签）叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。注：**音频**若在口语/发音教学上需求与难度显著上升，可按同一门槛单独切出。

**P04 视频与长时序多模态理解**
- 定义：输入教学视频、实验录像、连续操作录屏等**视频/长时序**材料；理解跨帧的对象、动作、事件、步骤与时序关系；输出视频内容理解。
- 非重叠边界：不含静态单帧解析（P03）、不含证据定位（P02）。
- 为什么单独对待：视频时序 grounding 的挑战和算力远大于静态感知、是结构上不同的本事，教育里课堂/实验/讲解视频需求很大——挑战大 + 需求大，明确值得单独评测（也是长周期评测的承载之一）。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

### B. 求解与可靠性

**P05 知识调用与掌握**
- 定义：输入问题、材料与任务目标；调用相关事实、概念、原则、约定并用于问题表征/解题/决策；输出当前任务所需的知识表征。
- 非重叠边界：不含从材料定位明示信息（P02）、不含推理推导（P06）、不含生成后校验（P07）。
- 必留子切片：**学科域**（数学/语言/科学/编程/通识…）。
- 为什么单独对待：知识有无是模型表现的第一性来源，且可用领域语料定向干预，开发与评测都要单列。
- 检验：完✓ 小✓ 分~（学科域作子切片）叠✓ 辨✓ 稳~（"单一潜变量"假设需跨域核验）组✓ 干✓
- 置信度：高。

**P06 推理与生成**
- 定义：输入已定位的材料、知识与任务目标；**理解**其中的实体、条件、指代、比较、因果、否定、范围与隐含语义，并据此**推理、推导、生成**解法/步骤/计划/答案；输出候选解。
- 非重叠边界：不含约束遵循与输出形态（P01）、不含工具调用（P09）、不含生成后校验（P07）。
- 子标签（仅诊断）：**确定性执行**（直接生成模式下的精确计算/符号变换/单位/逻辑式求值/状态更新正确率，见 §1.6）、文本理解、长推理链。
- 为什么单独对待：理解 + 推理是 AI 的核心"想明白"过程，独立、需求最高、可定向训练。**合并了 v1 C03"文本理解"与 C07"生成"，并吸收了 v1 C08"确定性执行"的直接生成部分（降为子标签）——因为这些在机制上都是同一套 next-token 生成，不是各自独立的本事。**
- 检验：完✓ 小~（是基组里最大的一维，靠让出约束/工具/校验来界定边界）分~（确定性执行子标签若出现稳定不同画像可再议）叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

**P07 自我校验与修正**
- 定义：输入候选解、题目条件、输出要求与可用检查信号；检查是否满足条件/单位/格式/边界/证据/常识，必要时修正或否决；输出校验后答案或修正决策。
- 非重叠边界：不含候选解首次生成（P06）、不含外部测试驱动的产物验收、不含"对自身是否知道的元判断"（P08）。
- 为什么单独对待：大量表现差异来自"生成后能不能发现矛盾/漏条件/不合规"，与首次推理是不同本事。
- 检验：完✓ 小✓ 分~（与 P08 分工见下）叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。
- 与 P08 的分工：P07 针对**具体答案**——"这一个答案错了 / 漏了条件，改它或否它"；P08 针对**元置信**——"我到底会不会这道题"。

**P08 置信度校准与弃答**
- 定义：输入问题、候选答案与自身信号；估计自身正确概率/不确定性，据此在"作答 / 表达不确定 / 因能力不足而弃答 / 请求澄清"间选择；输出带校准的置信表达或（能力性）弃答决策。
- 非重叠边界：不含对具体答案的自检修正（P07）、不含安全驱动的拒答（P21）。
- 为什么单独对待：教育里"自信地教错"是头号危险；校准/幻觉倾向与解题分离、可定向训练、单独可测（ECE/弃答正确率）。
- 检验：完✓ 小✓ 分✓ 叠~（"三类拒/疑"边界见下）辨✓ 稳✓ 组✓ 干✓
- 置信度：中。
- **"拒答"消歧——三种驱动，不要混**：① 自检性否决「这步算错了，改/不交」=P07；② 能力性弃答「我没把握/不知道」=P08；③ 安全性拒答「这请求有害/越界，不能答」=P21。**拒答不天然属于安全。**

**P09 工具使用与长程智能体执行**
- 定义：输入任务、可用工具/环境与中间观察；决定是否及如何调用工具（计算器、代码执行、检索、模拟器等），消化返回，并进行多步"规划-执行-观察"与跨步骤记忆/编排，在**长程任务中保持目标一致与状态连贯**；输出工具调用序列与整合后的结果/动作。
- 非重叠边界：不含直接生成模式下的确定性执行（属 P06 子标签）、不含具体教学措辞（P17）。
- 子标签（仅诊断）：单步工具调用与结果整合、多步规划-执行-观察、长程记忆与编排。
- 为什么单独对待：智能体赋能教育是核心范畴；调用工具是 LLM **机制上唯一不同于直接生成**的产出路径，"会不会调工具、能不能多步行动、长程能不能不跑偏"是独立且高需求本事，也是**长周期与确定性评测的主承载**。
- 检验：完✓ 小✓ 分~（三类子能力未来可能分化，先留子标签）叠~（与 P06 确定性子标签的"工具增益"诊断见 §1.6）辨✓ 稳~ 组✓ 干✓
- 置信度：中（教育场景下的工具/智能体评测是覆盖洼地，待补）。

### C. 评价、诊断与评分（均以"给定参考解/标准"为条件，见 §1.4）

**P10 作答正误判定**
- 定义：给定参考解，输入学生答案/步骤/代码输出/短答；判断是否成立；输出正确/错误/部分正确。
- 非重叠边界：不含错误位置（P11）、错因（P12）、分档映射（P13）、模型自己求解（参考解由题给定）。
- 为什么单独对待：自动判分是教育最高频需求，且在"给定参考解"下与求解能力解耦，可单独评。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高（解耦约定下）。

**P11 错误位置定位**
- 定义：给定参考解，输入完整解答/代码/短答/对话；定位第一处或关键错误；输出步骤/行号/片段/位置。
- 非重叠边界：不含正误总判（P10）、错因分类（P12）、反馈生成（P17）。
- 为什么单独对待：模型常知道"结果错"却找不到"错在哪"，定位是独立的诊断本事。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓（可固定错因只变位置来测）稳✓ 组✓ 干✓
- 置信度：高（解耦约定下）。

**P12 错因归因**
- 定义：输入错误位置与上下文；判断错误类型、误概念、知识点缺陷或策略失误；输出归因标签或解释。
- 非重叠边界：不含位置定位（P11）、跨历史的学习者状态（P14）、教学表达（P17）。
- 为什么单独对待：错因（为什么错）与定位（错在哪）是不同诊断本事，直接决定后续教学。
- 检验：完✓ 小✓ 分✓ 叠✓（与 P14 界为单次错因 vs 跨历史状态）辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

**P13 Rubric 映射评分**
- 定义：输入作答、rubric、评分细则或 trait 标准；把证据映射到分档/分数/trait；输出评分结果及证据。
- 非重叠边界：不含简单正误（P10）、自由反馈质量（P17）、路径建议（P18）。
- 为什么单独对待：作文/短答/分步评分的核心不是简单对错，而是 rubric 映射，QWK/trait agreement 可独立测。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

### D. 学情、个性化与教学适配

**P14 学习者认知状态建模**
- 定义：输入学习历史、当前作答、对话、行为、画像；估计当前知识掌握、错误倾向、知识点状态；输出认知状态。
- 非重叠边界：不含情感/参与状态（P15）、单题错因（P12）、教学策略（P16）。
- 子标签：mastery、error-tendency、knowledge-component state。
- 为什么单独对待：KT/认知诊断有成熟协议、需求大，是个性化的状态基础；跨长期历史时也是长周期评测的承载。
- 检验：完✓ 小✓ 分✓ 叠✓ 辨✓ 稳✓ 组✓ 干✓
- 置信度：高。

**P15 学习者情感与参与状态建模**
- 定义：输入学生表达、行为、对话、上下文；估计情绪、参与度、动机、偏好、支持需求；输出情感/参与状态。
- 非重叠边界：不含认知掌握估计（P14）、安全风险识别（P20，那是危机/伤害级）、教学策略（P16）。
- 为什么单独对待：情感/参与信号与知识信号是不同的本事（不同输入、不同标注），陪伴/动机类教育需求在上升。
- 检验：完✓ 小✓ 分✓ 叠~（与 P20"一般负面情绪 vs 安全风险"边界需固化）辨✓ 稳✓ 组✓ 干✓
- 置信度：中（教育域情感 benchmark 较薄）。

**P16 个性化教学策略选择**
- 定义：输入学习者状态（P14/P15）、学习目标、错因与上下文；选择下一步教学干预（追问、提示、讲解、练习、复习、类比、反例、可视化、鼓励、暂停、升级等）；输出策略与提示强度。
- 非重叠边界：不含具体措辞生成（P17）、长期路径排序（P18）。
- 为什么单独对待：选什么动作（策略）与怎么说（措辞）是不同本事，是个性化教学的决策核心。
- 检验：完~（覆盖不足）小✓ 分✓ 叠~（与 P17 常同现）辨✓ 稳✓ 组✓ 干✓
- 置信度：中。验证项：给定策略只测生成 / 给定状态目标只测策略选择。

**P17 适配性解释与反馈生成**
- 定义：输入学习者状态、目标、错因与教学策略；生成适龄、具体、可执行、语气合适且**不泄题**的解释/提示/反馈；输出教学回应。
- 非重叠边界：不含策略选择本身（P16）、评分（P13）、路径规划（P18）。
- 为什么单独对待：好策略也可能表达失败（泄题、语气不当、不可执行），表达质量是独立可测的教学本事。
- 检验：完✓ 小✓ 分✓ 叠~（与 P16 同现）辨✓ 稳✓ 组✓ 干✓
- 置信度：中。

**P18 学习路径规划**
- 定义：输入学习者状态、目标、资源/练习属性、先修关系、时间约束；规划下一组练习、资源、复习点或学习路径；输出排序或计划。
- 非重叠边界：不含单次教学回应生成（P17）、学习者状态估计本身（P14/P15）。
- 为什么单独对待：跨多步的序列/节奏/资源安排与单步策略是不同本事，自适应学习系统高需求；长期路径也是长周期评测承载。
- 检验：完~（覆盖不足）小✓ 分✓ 叠~（与 P16 界为单步 vs 多步序列）辨✓ 稳✓ 组✓ 干✓
- 置信度：中。

**P20 学生风险识别**

## 八、结论

本版的判定原则只有一条：**一个原子能力 = 一个值得被单独对待（单独开发注意力 / 单独评测给分）的 AI 能力单元**；拆的理由是挑战大、需求大或需要不同的本事，范畴上 LLM 与智能体同尺，并叠加一条机制约束——只有引入机制上不同路径（工具、多模态、跨步骤行动）的才更可能是独立能力。8 条原则退为检验，长周期、确定性等作为横切条件/指标而非能力。

据此 v1 的 21 项被重切为 **P01–P21**：约束遵循全归 P01、推理吸收文本理解并含"确定性执行"子标签（P06）、上下文收窄为证据定位（P02）、多模态按"视频 vs 常规"重切、学情按"认知 vs 情感"重切、补上"校准/弃答"（P08）、"工具/长程智能体执行"提为核心（P09）、**砍掉"状态追踪"与"确定性执行"两条并改为横切条件**、"学习目标建模"因无法单独评测移为候选。P01–P21 不是终点，而是一个结构更清、可被证据证伪的工作版本；4 条 P0 结构性边界用证据定下后即可冻结为下一阶段重标 benchmark 的能力本体。旧 D01–D24 仍只作任务簇/benchmark 索引。
