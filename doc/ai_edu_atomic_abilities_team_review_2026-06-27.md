# AI 教育原子能力框架 · 多角色团队评审与完善建议

日期：2026-06-27
方法：以四个角色组成评审团，各自独立审读 `doc/ai_edu_atomic_abilities.md`（及 `atomic_principle.md`、`atomic_ability_principle_audit_v2.md`），从本位视角提出完善意见，再由本文件汇总收敛。
关系：本文件是**评审结论与修改建议**，不直接改动正式框架；待采纳后再回写 `ai_edu_atomic_abilities.md`，并把分歧/候选项记入 `benchmark-todo.md`。

评审团构成：
- **人工智能专家**（LLM / 智能体 / 模型评测）
- **教育学 / 学习科学专家**（认知科学、教学法、教育测量）
- **一线教师**（中小学，长期批改 / 答疑 / 带班）
- **学生使用者**（中学生 / 大学生 / 自学者的综合体验）

---

## 一、一句话总判断

现框架是一份**优秀的"AI 批改 / 答疑助手"评测蓝图**：把"会解"与"会教"剥离（给定参考解）、评价诊断（P10–P13）与安全边界（P18–P20）切分扎实、方法论自洽。

四个角色从不同方向指向**同一个结构性偏差**：框架隐含地把"教学"建模为 **诊断 → 投递 → 守边界**，且几乎全程站在**施教者 / 评估者**视角。它系统性地弱化了三类东西——

1. **学生还没把问题摆上桌之前**的工作（判断真懂假懂、接住"不想学"、把内容讲活）；
2. **交互质感**（听懂模糊提问、不教晕、换种讲法、真诚而非塑料共情）；
3. **学习者长期主体性**（元认知 / 自我调节 / 独立性培养，避免制造依赖）。

此外 AI 专家指出框架缺少**"过程可信"维度**（推理忠实度 / 幻觉）与若干 2026 新失效模式（agentic 复合错误、谄媚、对抗鲁棒）。

## 二、各角色核心观点摘要

### 2.1 人工智能专家
- 结构健康：两层基组、跨层组合不算重叠、工具增益诊断、三驱动弃答分类（P07/P08/P20）均正确。
- 最该动的两处：**P09 把"单步工具可靠性"和"长程 agentic 执行"压成一格**，掩盖了复合错误失效；整套缺**"过程是否可信"**（推理忠实度 / 幻觉），与 P06 解对、P07 自检、P08 概率校准都正交。
- 隔离手段不足：现有 2 个隔离器（给参考解、确定性）测不到过程可信、agentic 内部归因、开放式教学决策；建议扩到 4 个（+ 植入错误检出、+ 扰动 / 反事实、+ 逐步金标轨迹）。
- 新失效模式：思维链忠实度 / 可监控性、越狱 / prompt injection、**谄媚（学生施压时是否守正解）**、agentic 复合错误率、跨模态推理。

### 2.2 教育 / 学习科学专家
- 最大结构缺口：**没有任何能力对应"逐步把调控权交还给学生"**（SRL / 支架渐撤 fading）；教育的终点是让学生不再需要老师。
- 被错误降格：**P12 错因归因不应只算"偏知识"**——从 PCK 与诊断教学看，从稀疏证据反推学生错误心智模型是最不可还原的教学专业判断。
- 方法论：给参考解隔离"会评 vs 会解"恰当，但**只覆盖收敛型评价**，系统性排除了"无标准答案的开放任务评价"和"识别非预期但正确的解法"——而这恰是高阶教师能力。
- **P14 认知 / 情感合并过激、不同构**：证据通道、构念动力学（认知慢变累积 vs 情感秒-分钟级波动）、真值验证、下游耦合都不同 → 应拆。
- 遗漏：元认知 / 学习策略指导、动机-情感主动培养（SDT / 控制-价值 / 成长型思维）、提问 / 证据获取质量（非反馈质量）、评估公平性 / 信度 / 偏见、学习成效闭环验证。

### 2.3 一线教师
- 框架假设了一个前提：**学生已经把问题摆上桌**。真实教学一半功夫花在这之前。
- 头号缺口：**识破"装懂"**——是**主动出探针**确认掌握，不是被动读历史（P14 接不住）。
- "不泄题"被当成近乎一刀切的默认禁令，是新手与 AI 的通病：**该给则给**（纯记忆题、学生崩了要保信心、时间不够、非今日重点）；**过度启发**和泄题一样不像老师。
- "不想学 / 畏难 / 走神" 90% 够不上 P19 危机级，却决定成败，框架在危机与日常之间是**断层**。
- P21 把"不冒犯底线"与"建立关系 / 激励"打包，导致"师者度"虚高（Tone 近饱和），**最难的部分没被测到**；"讲对"≠"讲得想听"（内容吸引力 / 动机化讲法）。
- 评测可拆 P10/P11/P12，但真实批改是一次性脑补完成，别据此对教师能力过度切分解读。
- 补：应试策略指导；家庭背景应作**红线约束**（不得据此降低期待）而非鼓励的能力。

### 2.4 学生使用者
- 判断"好不好用"的真实排序：听不听得懂我**乱七八糟的问题** → 会不会**把我教晕** → 反复追问会不会**换个讲法** → 是真想我学会还是**只想塞答案** → 让不让我**有信心** → 会不会让我**变懒依赖**。
- 最恼火的失效，框架多半测不到或没当回事：**答非所问、信息过载、复读式不换法、塑料共情**——都是交互质感问题，任务导向结构天然看不见。
- "不泄题"是单向"越克制越好"，**没把学生真实诉求当博弈另一方**：赶 due 时硬不给会被直接关掉；好 AI 该识别处境、拒绝时给台阶。
- 成年专家容易漏的点：**不被评判的心理安全**（敢问蠢问题是 AI 辅导最大独特价值）、**依赖 vs 自主的长期影响**、**跨水平公平**（别因我差就敷衍）、**学习者侧无障碍**（为看不见图的我把内容讲清楚，方向与 P03/P04 相反）、**脆弱信息隐私**（防 AI 自身滥用，而非只防外部风险）。

## 三、跨角色共识（高优先级，多方独立指向同一缺口）

下列每条都有 **≥2 个角色**独立提出，是最值得优先采纳的：

| # | 缺口 | 由谁提出 | 现框架最近的格子 / 为何接不住 |
| --- | --- | --- | --- |
| **G1** | **主动理解度探测 / 识破装懂**：主动出探针题、让学生复述 / 变式确认掌握，而非被动读历史 | 教师（头号）、学生（L1 邻接）、教育专家（形成性评估"证据获取"） | P14 假设懂 / 不懂能从作答历史读出；这是主动探测动作，机制不同 |
| **G2** | **非危机级动机 / 情绪的识别与回应**：畏难、抵触、走神、放弃、想放弃但够不上自伤 | 教师、教育专家（SDT / 控制-价值）、学生（信心） | P19/P20 只覆盖极端危机，P21 只管语气风格 → 危机与日常之间断层 |
| **G3** | **"给答案"的双向情境判断**：把"不泄题"从单向禁令改为按教学价值 / 学生状态 / 时间约束决定"给到几分"，拒绝时给台阶 | 教师、学生（L7） | P16"不泄题"是单向规范，未把学生诉求当博弈另一方；缺"该给则给" |
| **G4** | **P14 拆分：认知诊断 vs 情感-参与-动机推断** | 教育专家（不同构论证）、AI 专家（模型表现必然分化） | 现 P14 合并仅满足"表层同形"，违反框架自身"不可再分性"原则 |
| **G5** | **换表征重讲（anti-复读）**：学生说"没懂"后是否真换比喻 / 更小步，而非复读拉长 | 学生（L3）、教师（临场应变） | P22 含"换法"动词、P15 含"类比"，但未立为可观测失效点 |
| **G6** | **意图澄清 / 模糊提问对齐**：表达含糊、错误前提、术语用错时先确认真实意图 | 学生（L1）、教师（含糊答疑） | 仅在 P08 末尾作"弃答"子情形出现，未被单独重视 |
| **G7** | **元认知 / 自我调节 / 独立性培养（支架渐撤 fading）**：是在培养独立思考还是制造依赖 | 教育专家（SRL）、学生（L6 长期指标） | 框架完全空白；所有能力都是"这一轮好不好"，无长期主体性维度 |
| **G8** | **P21 拆层**：把"不冒犯底线" 与 "建立信任 / 激励 / 内容吸引力" 分开 | 教师、学生（L4 真诚 vs 塑料共情） | 现 P21 打包导致"师者度"虚高、最难部分测不到 |
| **G9** | **评估公平性 / 信度 / 偏见**（横切）：跨学习者水平、方言 / 二语 / 手写 / 背景的一致性 | 教育专家（Messick 效度）、学生（L9 跨水平公平、L10 无障碍） | P13 只谈"映射到 rubric"，无信度 / 偏见约束 |

## 五、分歧与权衡（需拍板，非直接采纳）

1. **是否新增大量"交互质感 / 学习者体验"原子（G3/G5/G6、S11–S13）？**
   - 张力：学生与教师视角强烈要求，但其中若干在评测上**无唯一金标**、易与 P16 共线，且现有 benchmark 区分度低（如 P21 Tone 近饱和）。
   - 建议折中：先以 **P16 / P22 的子维度 + 专门负例集**承载（如"复读 vs 真换表征""答非所问""塑料共情"做成对照题），跑出区分度后再决定是否升格为独立原子。**用数据而非直觉拍板拆合**（符合框架 §7 证据校准路线）。

2. **"师者度低信号"是真饱和还是数据稀疏？**
   - AI / 数据视角：MRBench Tone 1655 条仅 1 条 Offensive → 低区分度。
   - 学生 / 教师视角：那只测到了"不冒犯"底线一档，"建立关系 / 真诚激励"根本没进指标。
   - 结论倾向：**不是能力不重要，是当前指标测错了层**。配合 G8 拆层 + S9，需要新的高区分度评测协议，而非据现数据判其"不值得测"。

3. **家庭背景 / 差异对待（教师第 8 点）**
   - 教师明确警告：让 AI 据家庭背景调整期待**风险极高**（贴标签、降低期待）。
   - 结论倾向：**不立为鼓励的能力**，而作为 **P19/P21 的红线约束**（"不得据背景降低对学生的要求"），与 G9 公平性横切合并处理。

4. **P10/P11/P12 的拆分解读**
   - 评测层面：保留三拆（MRBench 已证 P10/P11 独立、20% 分离）。
   - 教师提醒：真实批改是一次性完成，**别把"评测维度"误读成"三种独立教学动作"对教师做能力画像**。建议在框架加一句解读护栏。

5. **协作学习引导 / 家校沟通**
   - 多为组合任务、且 1:1 tutor 场景可暂缓 → **记入 `benchmark-todo.md`**，不立原子。

## 六、建议的落地优先级

**第一梯队（共识强、机制清晰，优先回写框架）**
- G4 拆 P14（认知 / 情感）、S2 拆 P09（单步 / 长程）、S5 改 P12 类型、G8 拆 P21（底线 / 关系）。
- S1 新增"推理忠实度 / 幻觉"（操作基座）。
- 横切条件三连：S3 谄媚抗压、S4 对抗鲁棒、G9 公平 / 信度 / 偏见。

**第二梯队（立为教育原子或候选，需配评测协议）**
- G1 主动理解度探测、G2 非危机动机 / 情绪、G7 元认知 / 独立性培养（fading）、S7 学习增益闭环（候选 X2）。

**第三梯队（先做子维度 + 负例集，用数据决定是否升格）**
- G3 给答案双向判断、G5 anti-复读、G6 意图澄清、S6 开放任务评价、S8 提问质量、S9 内容吸引力、S10 应试策略、S11 认知负荷、S12 心理安全、S13 可追问性、S14 隐私、S15/S16 子标签。

**护栏与待办**
- 加解读护栏：P10/P11/P12 评测可拆 ≠ 教师三动作；家庭背景作红线而非能力。
- 记入 `benchmark-todo.md`：协作学习引导、家校沟通、多智能体协作（X 候选）。
