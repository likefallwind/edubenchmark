基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

根据《证券法》及《上市公司收购管理办法》的相关规定：
A 项错误：采用要约方式收购上市公司股份的，预定收购的股份比例通常没有 30% 的下限限制（30% 通常是触发热议收购要约的责任门槛，而非要约本身的最小收购比例，通常可以是 100% 减少收购，但需符合立法目的）。但在某些旧题库语境中，这往往被视为对“全面要约”的要求混淆。实际上，30% 是持股达到触发全面要约收购的警戒线，而非要约收购本身必须收购 30% 以上。最新的《上市公司收购管理办法》并没有规定要约收购必须不低于 30%。
B 项错误：要约收购期间，收购人不得撤销收购要约（原则上），但**可以**变更收购要约（如延长要约期限或增加要约价格等），变更受到一定限制。
C 项正确：根据题点的“上市公司收购的特别规定”，收购同一上市公司的同一品种股票，其要约价格不得低于该上市公司收购公告日前 12 个月内收购人所取得的该种股票的最高价（基于经典《证券法》及旧《收购管理办法》的考点，这是为了防止低价收购造成市场震荡或损害股东利益）。虽然 2020 年证券法修订后具体统计天数有变化，但在注册会计师（CPA）历史经典题库及现行考试的“特别规则”逻辑中，关于“价格不低于收购期间最高价”的规则是经常被考察的核心点。
D 项错误：要约收购期间，被收购公司的董事、监事、高级管理人员**可以**因正常情况辞职，法律主要限制的是被收购公司不得**转移或解散**、不得**变更控股股东**等影响收购进程的行为，虽然限制其董事会换届以稳定股价，但“不得辞职”的表述过于绝对，且在实务中通常理解为限制其**主动离职以操纵控制权**。相较之下，C 项关于要约价格底线的规定是更为明确的硬性法律条款。

#ceval::advanced_mathematics-val-3source_benchmark=ceval language=zh
设函数$f\left(x\right)$连续，且$f\left(x\right)>0$，求积分：$int_0^1{\ln f\left(x+t\right)}\mathrm{d}t=$____ A. $\int_0^x{\ln \frac{f\left( t+2 \right)}{f\left( t \right)}}\mathrm{d}t+\int_0^1{\ln f\left( t \right)}\mathrm{d}t$ B. $\int_0^1{\ln \frac{f\left( t+2 \right)}{f\left( t \right)}}\mathrm{d}t+\int_0^1{\ln f\left( t \right)}\mathrm{d}t$ C. $\int_0^2x{\ln \frac{f\left( t+1 \right)}{f\left( t \right)}}\mathrm{d}t+\int_0^1{\ln f\left( t \right)}\mathrm{d}t$ D. $\int_0^x{\ln \frac{f\left( t+2 \right)}{f\left( t \right)}}\mathrm{d}t+\int_0^1{\ln f\left( t \right)}\mathrm{d}t$ 答案：
模型抽取答案{"a": "C", "c": 98}
归一化C
正确答案A
查看模型完整作答
\text{c}
\text{答案：C}
\text{解析：}
\text{原设为 } I = \int_0^1 \ln f(x+t) \, dt。
\text{令 } u = x+t，则 \, du = dt。
\text{当 } t=0 \text{ 时，} u=x；当 t=1 \text{ 时，} u=x+1。
\text{则 } I = \int_x^{x+1} \ln f(u) \, du。
\text{利用积分区间拆分性质：}
\int_x^{x+1} \ln f(u) \, du = \int_0^{x+1} \ln f(u) \, du - \int_0^x \ln f(u) \, du
\text{进一步拆分第一项：}
\int_0^{x+1} \ln f(u) \, du = \int_0^1 \ln f(u) \, du + \int_1^{x+1} \ln f(u) \, du。
\text{在 } \int_1^{x+1} \ln f(u) \, du \text{ 中，令 } t = u-1，du = dt。
\text{积分限变为 } t=0 \text{ 到 } t=x。积分项变为 } \ln f(t+1)\\text{。}
\text{故 } \int_1^{x+1} \ln f(u) \, du = \int_0^x \ln f(t+1) \, dt。
\text{代回原式：}
I = \int_0^1 \ln f(t) \, dt + \int_0^x \ln f(t+1) \, dt - \int_0^x \ln f(t) \, dt
I = \int_0^1 \ln f(t) \, dt + \int_0^x \left( \ln f(t+1) - \ln f(t) \right) dt
I = \int_0^1 \ln f(t) \, dt + \int_0^x \ln \frac{f(t+1)}{f(t)} \, dt。
\text{对比选项：}
A 项和 D 项中将被积函数的分子中的自变量写为 $t+2$，推导结果应为 $t+1$。
B 项积分限为 $0$ 到 $1$，结果为常数，与 $x$ 有关。
C 项形式为 $\int_0^{\text{something}} \ln \frac{f(t+1)}{f(t)} \, dt + \int_0^1 \ln f(t) \, dt，其中自变量为 $t+1$，与推导结果一致（尽管题干中积分上限"$2x$"有录入错误，通常应为$x$）。
\text{因此 C 是正确答案。}

在行业生命周期理论中，成熟期的特点是市场增长率下降，竞争加剧，市场趋于饱和。对于大企业而言，由于已经建立了较大的市场地位，盲目追求增长往往难以实现且风险较高。此时的主要任务是保持现有市场份额和盈利能力，这通常通过维持现状、优化资源配置和进行稳健经营来实现，因此“稳定型战略”是这一阶段大企业最常匹配的战略选择。虽然“成本领先”也是成熟期大企业常用的战术，但选项中的“成本集聚战略”并非标准术语（通常指成本领先），而“稳定型战略”是生命周期理论与企业战略匹配中的标准对应答案。
