基准介绍

K12Vista 是目前规模最大的中文 K12 多模态学科基准：33,660 道题，覆盖数学、物理、化学、生物、地理五个学科与小学/初中/高中三个学段，题型含选择题、填空题、问答题，每题都带一张学科图（几何图、电路图、实验装置、函数曲线、地图等），必须先看懂图才能作答。对应本仓库能力 P04（复杂多模态理解），也是中文多模态的短板补位。

本次评测使用固定抽样题单（600 题，按题型×学科-学段分层——即官方评测的汇总轴，见 data/k12vista/item_list_v2.txt），所有模型跑同一份题，保证横向可比。难度只作报告分桶：该标签为数据自带、论文未说明来源，且全量分布极偏（71.7% 难）。

提示词与判分口径均照搬官方仓库：作答走官方 directly_infer_prompt（按题型分三种），判分走官方 directly_eval_prompt——裁判逐空提取参考答案与学生答案并给 0/1，题分＝各空得分均值（多空题部分给分）。表头 accuracy 是严格全对率，官方口径的部分给分均值在 extra_metrics.official_score。

注意：官方裁判是 GPU 部署的 Qwen2.5-VL-72B / K12-PEM，本地无法复现，此处改用 API 裁判（K12VISTA_JUDGE_MODEL），rubric 文本未改但裁判模型不是官方那一个，且该裁判未经人工金标校准。

# 霍尔效应分析

## 设置坐标系
- 电流 I 沿 +x 方向
- 磁场 B 沿深度方向（沿 d 方向）
- 霍尔电压沿竖直方向（沿 h 方向）

## 分析各选项

**霍尔电压公式：** 
$$U_H = \frac{IB}{ned}$$
其中 d 是磁场方向上的尺寸（深度），h 是霍尔电压方向上的尺寸（高度）。

**推导：** 设载流子漂移速度 $v_x = \frac{I}{neA} = \frac{I}{nedh}$，平衡时 $eE = ev_xB$，故 $U_H = E \cdot h = v_x B \cdot h = \frac{IB}{ned}$

### 选项 A：上表面电势高 ✓
对金属中的电子，洛伦兹力 $\vec{F} = -e\vec{v} \times \vec{B}$ 方向向下，电子聚集在下表面，下表面电势低，上表面电势高。**正确**

### 选项 B：仅增大 h，电压不变 ✓
由 $U_H = \frac{IB}{ned}$，公式中不含 h，增大 h 时：
- 截面积增大，漂移速度减小
- 但霍尔电压方向上的尺寸 h 增大
- 两者恰好抵消，$U_H$ 不变。**正确**

### 选项 C：仅增大 d，电压减小 ✓
由 $U_H = \frac{IB}{ned}$，d 在分母中，增大 d 使 $U_H$ 减小。**正确**

### 选项 D：仅增大 I，电压减小 ✗
由 $U_H = \frac{IB}{ned}$，I 在分子中，增大 I 使 $U_H$ 增大。**错误**

# 解答

## （1）P、Q间电场强度E的大小

导体棒a绕O点匀速转动产生的电动势：
$$\varepsilon = \frac{1}{2}B\omega l^2$$

在稳态下，电容器支路无电流通过，所以电容器两端电压等于电源电动势：
$$U_{PQ} = \varepsilon = \frac{1}{2}B\omega l^2$$

因此P、Q间电场强度为：
$$\boxed{E = \frac{B\omega l^2}{2d}}$$

## （2）小球通过N点时对细线拉力T的大小

设细线长度为L。小球从M点（绳水平位置）运动到N点（M点正下方，圆弧最低点）：

**能量守恒分析：**
由于M点和N点的水平位置相同（Δx = 0），水平方向的电场力不做功，只有重力做功：
$$\frac{1}{2}mv^2 = mgL$$
$$v^2 = 2gL$$

**N点受力分析：**
N点为圆周最低点，向心加速度方向竖直向上。此时电场力（水平方向）不影响竖直方向的圆周运动：
$$T - mg = \frac{mv^2}{L}$$

代入 $v^2 = 2gL$：
$$T = mg + \frac{m \cdot 2gL}{L} = 3mg$$

由牛顿第三定律，小球对细线的拉力：
$$\boxed{T = 3mg}$$
