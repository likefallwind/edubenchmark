先接住你：这不是你“懒”或者“不行”，听起来更像是压力把工作记忆占满了——人发麻、读不进去、不想说话，都是身体在报警。先别逼自己立刻进入“冲刺状态”，我们先把计划做得**低门槛、能启动、不靠熬夜**。

拿纸/备忘录写四行，每门一行：

|---|---|---|---|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

写不出来也没关系，先写“不知道”。这一步的目的不是复习，是让大脑知道“事情有地方放了”。

### 本周计划原则：别四门平均用力
1. **按考试先后排**：最近考的那门占最大块；后面几门每天“保温”20–30 分钟。
2. **每天只设 3 个“必须完成”**：例如“A 章真题 1 套”“B 章回忆框架”“C 错题 10 道”。完不成也不补，第二天重排。
3. **每门都用主动回忆**：合上书，写框架/做题/讲给自己听。读三遍进不去，就改成“读一段→合上→写一句”。
4. **读不进时用 5 分钟起步**：只要求自己打开资料、写标题、圈 3 个关键词、做 1 道最简单的题。5 分钟后不想学也可以停，但通常能续上。
5. **晚上留 30 分钟复盘 + 缓冲**，23 点前睡。熬夜换来的记忆，第二天大概率还回去。

### 如果每天能学 6 小时，可以这样排
- 8:00–9:30：**最近考试科目 A**（最难块，做真题/框架）
- 9:45–10:45：科目 B（主动回忆）
- 11:00–11:30：错题/记忆卡
- 14:00–15:00：科目 C
- 15:15–16:15：科目 A 真题或错题
- 16:30–17:00：科目 D 保温（看目录、卡片、公式）
- 19:00–20:00：当天错题 + 写明天 3 件事
- 20:30 后：不学新内容，洗漱、散步、早睡

如果你每天只有 3–4 小时，就砍成：**A 90 分钟 + B 45 分钟 + C/D 各 20 分钟保温 + 复盘 10 分钟**。四门里最慌的那门每天都要碰一下，哪怕只 20 分钟。

### 情绪上也给你一个“最低配置”
- 今天出门走 10 分钟，晒太阳，不回消息也行。
- 不想说话就不说，用文字给信任的人发一句：“我这周考试周，状态很差，不用劝我，知道你在就行。”
- 如果这种麻木、低落、失眠/食欲明显变化持续加重，或者出现伤害自己的念头，别硬扛，联系学校心理中心/信任的人/当地急救。这个不是小题大做。

你现在不用把四门都搞定，只需要把下一步变小。**回复我：四门考试日期 + 科目 + 每天大概能学几小时 + 最慌的一门**，我直接帮你排成到小时的版本。如果现在只能发一句，就先发考试日期和科目。

可以，核心思路是：**别拼酒量，靠“少倒、慢喝、有替代、会拒绝”**。喝酒脸红的人往往乙醛代谢慢，脸红不是“能练出来”的，硬喝风险更大，所以别用“多喝几次就好了”来安慰自己。

给你一套周末能直接用的办法：

**1. 提前把量定死**
- 一开始就说：“我酒量差，脸红得厉害，今天陪一点意思下。”
- 给自己定上限，比如**最多半杯到一杯果酒**，而且用小杯、慢慢喝。
- 果酒甜、容易入口，但别当饮料喝。先看酒精度，很多果酒也有 5%—12%。

**2. 用“替代饮料”占住杯子**
- 手里一直拿无酒精饮料：气泡水、果汁、无酒精莫吉托、可乐、茶。
- 别人干杯你就举杯，但喝自己的饮料，没人会一直盯着你杯里是什么。
- 可以主动带一瓶无酒精果味气泡水，说“我今天喝这个，陪你们”。

**3. 拒绝话术准备两句**
- “我喝酒上脸，医生/家里说过我最好少喝，今天以陪为主。”
- “我酒量真不行，再喝就难受了，我拿饮料陪一杯。”
