正确答案$30^{\circ}$
查看模型完整作答
Let $\angle ACB = x$.

**Using the perpendicular bisector:** Since $T$ lies on the perpendicular bisector of $BC$, $TB = TC$, so triangle $TBC$ is isosceles and $\angle TBC = \angle TCB = x$. Therefore
$$\angle BTC = 180^\circ - 2x,$$
and since $A, T, C$ are collinear, $\angle ATB = 180^\circ - \angle BTC = 2x$ (exterior angle).

**Using the isosceles triangle $ABT$:** Since $AT = AB$, the angles opposite these sides are equal:
$$\angle ABT = \angle ATB = 2x.$$

**Angle sum in triangle $ABT$:** Since $\angle ABC = 90^\circ$, we have $\angle A = 90^\circ - x$. Then
$$(90^\circ - x) + 2x + 2x = 180^\circ \implies 90^\circ + 3x = 180^\circ \implies x = 30^\circ.$$

So the final answer is \boxed{30}
#OE_MM_maths_en_COMP-2533subject=Math language=en modality=MM answer_type=Numerical

Please end your solution with "So the final answer is \boxed{answer}." and give the result explicitly. In the diagram, $\triangle A B C$ is right-angled at $C$. Also, $2 \sin B=3 \tan A$. Determine the measure of angle $A$. <image_1>
模型抽取答案\boxed{30}
归一化30
正确答案$30^{\circ}$
查看模型完整作答
Let angle $A = \alpha$. Since the triangle is right-angled at $C$, we have $B = 90^\circ - \alpha$, so:

$$\sin B = \sin(90^\circ - \alpha) = \cos\alpha$$

**Setting up the equation:**

$$2\sin B = 3\tan A \implies 2\cos\alpha = \frac{3\sin\alpha}{\cos\alpha}$$

**Solving:**

$$2\cos^2\alpha = 3\sin\alpha$$

Using $\cos^2\alpha = 1 - \sin^2\alpha$ and letting $s = \sin\alpha$:

$$2(1 - s^2) = 3s \implies 2s^2 + 3s - 2 = 0$$

Factoring:

$$(2s - 1)(s + 2) = 0$$

So $s = \frac{1}{2}$ (the root $s = -2$ is rejected since $\sin\alpha > 0$).

Therefore $\sin A = \frac{1}{2}$, which gives $A = 30^\circ$.

**Check:** If $A = 30^\circ$, then $B = 60^\circ$.
- $2\sin B = 2\cdot\frac{\sqrt{3}}{2} = \sqrt{3}$
- $3\tan A = 3\cdot\frac{1}{\sqrt{3}} = \sqrt{3}$ ✓

So the final answer is \boxed{30}

**Step 1: Find AC using the Law of Cosines in triangle ABC.**

With $AB = 21$, $BC = 16$, and $\angle ABC = 60^\circ$:

$$AC^2 = 21^2 + 16^2 - 2(21)(16)\cos 60^\circ = 441 + 256 - 672 = 25$$

So $AC = 5$.

**Step 2: Use the Law of Sines in triangle ACD.**

The angles are $\angle CAD = 30^\circ$, $\angle ACD = 45^\circ$, so $\angle ADC = 180^\circ - 30^\circ - 45^\circ = 105^\circ$.

By the Law of Sines:

$$\frac{CD}{\sin \angle CAD} = \frac{AC}{\sin \angle ADC}$$

$$CD = \frac{5 \sin 30^\circ}{\sin 105^\circ}$$

Since $\sin 105^\circ = \sin 60^\circ \cos 45^\circ + \cos 60^\circ \sin 45^\circ = \frac{\sqrt{6}+\sqrt{2}}{4} \approx 0.9659$:

$$CD = \frac{5 \cdot 0.5}{0.9659} \approx \frac{2.5}{0.9659} \approx 2.588$$

Rounded to the nearest tenth, $CD \approx 2.6$.

So the final answer is \boxed{2.6}.
