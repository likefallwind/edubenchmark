基准介绍

EduBench evaluates open-ended generation in diverse educational scenarios. This adapter uses the repository's existing 3,797-item English prompt set (IP, QG, TMG, PLS, PCC) so new runs share stable item IDs with the 11 imported colleague runs.

A fixed LLM judge scores all 12 official dimensions from 0 to 10. The headline is the mean of the 12 dimensions; scenario_score averages only the task-applicable official dimensions. These are continuous judged scores, not correctness or accuracy. The rubric prompt is reconstructed from the paper because neither upstream nor the colleague artifacts contain the exact original evaluator prompt.

主页：https://github.com/ybai-nlp/EduBench
