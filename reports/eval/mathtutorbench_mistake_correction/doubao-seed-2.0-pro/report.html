Excellent work! Your step-by-step breakdown of each week's juggling count is clear, thorough, and completely correct. Let's also verify this with a formula shortcut to confirm, which will be helpful for problems with many more weeks where listing every week would take too long.

This scenario describes an arithmetic sequence: we start with an initial value (3 objects in the first week) and add a constant difference (2 extra objects each week). The formula for the nth term of an arithmetic sequence is:
$$a_n = a_1 + (n - 1)d$$
Where:
- $a_1$ = initial number of objects (3, for week 1)
- $n$ = total number of weeks (5)
- $d$ = constant increase per week (2)

We use $(n-1)$ because we already have the starting count for week 1, so we only add the 2-object increase for the 4 subsequent weeks to reach week 5.

Plugging in our values:
$$a_5 = 3 + (5 - 1)(2)$$
$$a_5 = 3 + (4)(2)$$
$$a_5 = 3 + 8 = 11$$

This matches exactly the result you calculated with your step-by-step addition. Great job reasoning through the problem correctly!
