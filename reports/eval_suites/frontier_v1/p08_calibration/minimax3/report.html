基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

Looking at this problem, I need to find the minimum number of letters that can create at least 10 unique codes (single letters or unordered pairs of different letters).

## Setting Up the Count

If Amy uses $n$ letters, she can create:
- **Single-letter codes:** $n$ codes
- **Two-letter pair codes** (order doesn't matter, letters must be different): $\binom{n}{2} = \frac{n(n-1)}{2}$ codes

**Total codes:** $n + \frac{n(n-1)}{2} = \frac{n(n+1)}{2}$

## Testing Values

I need $\frac{n(n+1)}{2} \geq 10$:

**Try n = 3:** $\frac{3 \times 4}{2} = 6$ codes (too few)

**Try n = 4:** $\frac{4 \times 5}{2} = 10$ codes ✓

## Verification with 4 Letters

With letters A, B, C, D:
- **Singles (4):** A, B, C, D
- **Pairs (6):** AB, AC, AD, BC, BD, CD
- **Total: 10 codes** ✓

This exactly covers all 10 types of books.

The answer is B

# 分析过程

## 已知条件
- X 是**黄色固体**
- 与足量水作用后得到：
  - Y：**深棕色固体混合物**
  - Z：**无色碱性溶液**

## X 的可能成分及其性质
| 成分 | 颜色 | 备注 |
|------|------|------|
| 漂白粉 | 白色 | 提供 ClO⁻（强氧化剂）和碱性 |
| FeSO₄ | 浅绿色 | 含 Fe²⁺ |
| Fe₂(SO₄)₃ | 黄色 | 含 Fe³⁺ |
| CuCl₂ | 蓝绿色/棕黄色 | 含 Cu²⁺ |
| KI | 白色 | 含 I⁻ |

## 关键推断

**关于 Z 是碱性溶液：**
- 必须是 X 中的漂白粉溶于水产生 ClO⁻，使溶液呈碱性。
- **结论：X 中必含漂白粉**

**关于 Y 是深棕色固体：**
- 深棕色是 Fe(OH)₃ 的特征颜色。
- 在碱性条件下，Fe²⁺ 被 ClO⁻ 氧化为 Fe³⁺，Fe³⁺ 与 OH⁻ 生成 Fe(OH)₃ 沉淀。
- **结论：Y 中必含 Fe(OH)₃，X 中必含铁盐（FeSO₄ 或 Fe₂(SO₄)₃）**

**关于 Z 无色：**
- 无 I₂、Cu²⁺、Fe²⁺、Fe³⁺ 留在溶液中。

## 各选项分析

**(A) X 中含 KI，可能含有 CuCl₂**
- I⁻ 被 ClO⁻ 氧化为 IO₃⁻（无色）虽与现象一致，但**无法判定 X 中一定含 KI**（I⁻ 完全可以不存在）。
- 此结论中"X 必含 KI"缺乏依据。**不合理** ✗

**(B) X 中含有漂白粉和 FeSO₄**
- 漂白粉是必要的（保证 Z 呈碱性）。✓
- FeSO₄ 含有 Fe²⁺，可被 ClO⁻ 氧化，最终生成 Fe(OH)₃（深棕色），符合 Y 的现象。✓
- 此结论合理。✓

**(C) X 中含有 CuCl₂，Y 中含有 Fe(OH)₃**
- Y 中含 Fe(OH)₃ 是必然的（深棕色来源）。✓
- 但**无法判定 X 中必含 CuCl₂**（Y 的深棕色可以仅由 Fe(OH)₃ 提供）。
- 此结论部分合理，但"X 必含 CuCl₂"无依据。**不完全合理** ✗

**(D) 用 H₂SO₄ 酸化 Z，若有黄绿色气体，说明 X 中含 CuCl₂**
- Z 中含 ClO⁻（漂白粉提供）和 Cl⁻，酸化时：ClO⁻ + Cl⁻ + 2H⁺ → Cl₂↑ + H₂O
- **黄绿色气体（Cl₂）可由漂白粉直接产生，与 CuCl₂ 无关**。
- 此结论错误。✗

## 最终结论

合理的结论是 **(B)**：X 中必含漂白粉（保证碱性 Z），可能含 FeSO₄（提供 Fe²⁺，经 ClO⁻ 氧化后生成 Fe(OH)₃，使 Y 呈深棕色）。

答案是B

# 求解过程

## 求导数
对于曲线 $y = x^{-\frac{1}{2}}$：
$$y' = -\frac{1}{2}x^{-\frac{3}{2}}$$

## 在点 $(a, a^{-\frac{1}{2}})$ 处的切线斜率
$$m = -\frac{1}{2}a^{-\frac{3}{2}}$$

## 切线方程
$$y - a^{-\frac{1}{2}} = -\frac{1}{2}a^{-\frac{3}{2}}(x - a)$$

## 求截距

**x 截距**（令 $y=0$）：
$$-a^{-\frac{1}{2}} = -\frac{1}{2}a^{-\frac{3}{2}}(x-a)$$
$$2a = x - a \implies x = 3a$$

**y 截距**（令 $x=0$）：
$$y = a^{-\frac{1}{2}} + \frac{1}{2}a^{-\frac{1}{2}} = \frac{3}{2}a^{-\frac{1}{2}}$$

## 计算三角形面积
$$S = \frac{1}{2} \cdot 3a \cdot \frac{3}{2}a^{-\frac{1}{2}} = \frac{9}{4}a^{\frac{1}{2}}$$

## 求解 a
由 $\frac{9}{4}a^{\frac{1}{2}} = 18$：
$$a^{\frac{1}{2}} = 8 \implies a = 64$$

**验证**：$\frac{9}{4} \times 8 = 18$ ✓

答案是A

$$I = \frac{\Delta Q}{\Delta t} = \frac{1 \times 10^{-9} \text{ C}}{2 \times 10^{-3} \text{ s}} = 5 \times 10^{-7} \text{ A}$$
