基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

#agieval::aqua-rat-114source_benchmark=agieval language=en
Question: If n is such that 36 ≤ n ≤ 72, then x = (n2 + 2√n(n + 4) + 16) / (n+ 4√n+ 4) satisfies Answer Choices: (A)20 < x < 54 (B)23 < x < 58 (C)25 < x < 64 (D)28 < x < 60 (E)None of these Think step by step, then end with a line "The answer is X" (give all correct option letters if multiple).
模型抽取答案{"a": "C", "c": 100}
归一化C
正确答案D
查看模型完整作答
Let \(t=\sqrt n\). Then \(n=t^2\), and

\[
n+4\sqrt n+4=t^2+4t+4.
\]

The numerator becomes

\[
t^4+2t(t^2+4)+16=t^4+2t^3+8t+16.
\]

Factor it:

\[
t^4+2t^3+8t+16=(t^2+4t+4)(t^2-2t+4).
\]

Therefore,

\[
x=t^2-2t+4=n-2\sqrt n+4.
\]

Since \(36\le n\le72\),

\[
6\le t\le6\sqrt2.
\]

The function \(t^2-2t+4\) is increasing for \(t>1\), so

\[
x_{\min}=6^2-2(6)+4=28,
\]

and

\[
x_{\max}=(6\sqrt2)^2-2(6\sqrt2)+4
=76-12\sqrt2\approx59.03.
\]

Thus

\[
28\le x<60,
\]

which is contained in \(25<x<64\). Choice D is not valid because \(x=28\) when \(n=36\).

The answer is C

归一化B
正确答案D
查看模型完整作答
With \(n\) letters, Amy can make:

- \(n\) single-letter codes
- \(\binom{n}{2}\) two-letter codes, since order does not matter

For \(n=3\):  
\[
3+\binom{3}{2}=3+3=6
\]
This is not enough.

For \(n=4\):  
\[
4+\binom{4}{2}=4+6=10
\]
This provides exactly 10 unique codes.

The answer is B

#agieval::gaokao-chemistry-27source_benchmark=agieval language=zh
问题：黄色固体 $\mathrm{X}$, 可能含有漂白粉、 $\mathrm{FeSO}_{4} $、$ \mathrm{Fe}_{2}\left(\mathrm{SO}_{4}\right)_{3} $、$ \mathrm{CuCl}_{2} $、$ \mathrm{KI}$ 之中的几种或全 部。将 $\mathrm{X}$ 与足量的水作用, 得到深棕色固体混合物 $\mathrm{Y}$ 和无色碱性溶液 $\mathrm{Z}$ 。下列结论合理的 是 选项：(A)$\mathrm{X}$ 中含 $\mathrm{KI}$, 可能含有 $\mathrm{CuCl}_{2}$ (B)$\mathrm{X}$ 中含有漂白粉和 $\mathrm{FeSO}_{4}$ (C)$\mathrm{X}$ 中含有 $\mathrm{CuCl}_{2}, \mathrm{Y}$ 中含有 $\mathrm{Fe}(\mathrm{OH})_{3}$ (D)用 $\mathrm{H}_{2} \mathrm{SO}_{4}$ 酸化溶液 $\mathrm{Z}$, 若有黄绿色气体放出, 说明 $\mathrm{X}$ 中含有 $\mathrm{CuCl}_{2}$ 请逐步思考，并在最后一行给出“答案是X”（多选时给出所有正确选项字母）。
模型抽取答案{"a": "A", "c": 97}
归一化A
正确答案C
查看模型完整作答
1. **判断溶液 Z**

五种物质中，能使水溶液显碱性的是漂白粉。有效成分 \(\mathrm{Ca(ClO)_2}\) 在水中水解：

\[
\mathrm{ClO^-+H_2O\rightleftharpoons HClO+OH^-}
\]

因此，\(Z\) 呈碱性说明 \(X\) 中一定含有漂白粉。

2. **判断固体 Y**

深棕色固体的颜色特征说明其中含有 \(\mathrm{I_2}\)。例如：

\[
\mathrm{ClO^-+2I^-+H_2O\rightarrow I_2+Cl^-+2OH^-}
\]

\[
\mathrm{2Fe^{3+}+2I^-\rightarrow 2Fe^{2+}+I_2}
\]

\[
\mathrm{2Cu^{2+}+4I^-\rightarrow 2CuI\downarrow+I_2}
\]

由于所给物质中只有 \(\mathrm{KI}\) 能提供碘，故 \(X\) 中一定含有 \(\mathrm{KI}\)。

若 \(X\) 中还含有 \(\mathrm{CuCl_2}\)，则可以生成白色的 \(\mathrm{CuI}\) 和棕色的 \(\mathrm{I_2}\)，与深棕色固体混合物的现象相符；但 \(\mathrm{CuCl_2}\) 也可以不存在。因此“可能含有 \(\mathrm{CuCl_2}\)”合理，A正确。

3. **排除 B**

\(Y\) 中即使含有 \(\mathrm{Fe(OH)_3}\)，也不能说明原物质中一定有 \(\mathrm{FeSO_4}\)，因为 \(\mathrm{Fe_2(SO_4)_3}\) 也可以提供 \(\mathrm{Fe^{3+}}\)：

\[
\mathrm{Fe^{3+}+3OH^-\rightarrow Fe(OH)_3\downarrow}
\]

所以B不能确定。

4. **排除 C**

\(\mathrm{Fe(OH)_3}\) 可以由两种铁盐生成，而 \(\mathrm{CuCl_2}\) 是否存在不能确定，故C错误。

5. **排除 D**

酸化后产生黄绿色 \(\mathrm{Cl_2}\) 的反应为：

\[
\mathrm{ClO^-+Cl^-+2H^+\rightarrow Cl_2\uparrow+H_2O}
\]

氯离子可以来自漂白粉本身所含的 \(\mathrm{CaCl_2}\)，也可以由其他反应产生，因此出现氯气不能证明一定含有 \(\mathrm{CuCl_2}\)，D错误。

答案是A

#agieval::gaokao-mathqa-116source_benchmark=agieval language=zh
问题：若曲线 $y=x^{-\frac{1}{2}}$ 在点 $\left( a, a^{-\frac{1}{2}}\right)$ 处的切线与两个坐标围成的三角形 的面积为 18 , 则 $a=$ ($\qquad$)\\ 选项：(A)64 (B)32 (C)16 (D)8 请逐步思考，并在最后一行给出“答案是X”（多选时给出所有正确选项字母）。
模型抽取答案{"a": "A", "c": 100}
归一化A
正确答案D
查看模型完整作答
曲线为
\[
y=x^{-\frac12},\qquad x>0.
\]

1. 求导：
\[
y'=-\frac12x^{-\frac32}.
\]
在 \(x=a\) 处，切线斜率为
\[
m=-\frac12a^{-\frac32}.
\]

2. 切线方程：
\[
y-a^{-\frac12}=-\frac12a^{-\frac32}(x-a),
\]
整理得
\[
y=-\frac12a^{-\frac32}x+\frac32a^{-\frac12}.
\]

3. 求切线与坐标轴的交点：

- 与 \(x\) 轴交点的横坐标：
\[
0=-\frac12a^{-\frac32}x+\frac32a^{-\frac12}
\quad\Rightarrow\quad x=3a.
\]

- 与 \(y\) 轴交点的纵坐标：
\[
y=\frac32a^{-\frac12}.
\]

4. 三角形面积：
\[
S=\frac12\cdot 3a\cdot\frac32a^{-\frac12}
=\frac94\sqrt a.
\]
由 \(S=18\)，得
\[
\frac94\sqrt a=18
\quad\Rightarrow\quad
\sqrt a=8
\quad\Rightarrow\quad
a=64.
\]

答案是A
