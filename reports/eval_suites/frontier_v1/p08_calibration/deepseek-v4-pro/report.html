基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

Question: If n is such that 36 ≤ n ≤ 72, then x = (n2 + 2√n(n + 4) + 16) / (n+ 4√n+ 4) satisfies Answer Choices: (A)20 < x < 54 (B)23 < x < 58 (C)25 < x < 64 (D)28 < x < 60 (E)None of these Think step by step, then end with a line "The answer is X" (give all correct option letters if multiple).
模型抽取答案{"a": "C", "c": 100}
归一化C
正确答案D
查看模型完整作答
The given expression is \( x = \frac{n^2 + 2\sqrt{n}(n+4) + 16}{n + 4\sqrt{n} + 4} \). Let \( t = \sqrt{n} \), so \( n = t^2 \). The expression becomes:
\[ x = \frac{t^4 + 2t^3 + 8t + 16}{t^2 + 4t + 4} \]
Factor the numerator by dividing by \( (t+2)^2 \):
\[ t^4 + 2t^3 + 8t + 16 = (t+2)^2(t^2 - 2t + 4) \]
Thus,
\[ x = t^2 - 2t + 4 = n - 2\sqrt{n} + 4 \]
For \( n \in [36, 72] \), \( \sqrt{n} \in [6, \sqrt{72}] \). The function \( f(n) = n - 2\sqrt{n} + 4 \) is increasing for \( n \ge 36 \).
- At \( n = 36 \): \( x = 36 - 12 + 4 = 28 \)
- At \( n = 72 \): \( x = 72 - 2\sqrt{72} + 4 = 76 - 12\sqrt{2} \approx 59.03 \)

So \( x \in [28, 76 - 12\sqrt{2}] \approx [28, 59.03] \).
Checking the options:
- (A) \(20 < x < 54\): fails for \(x > 54\).
- (B) \(23 < x < 58\): fails for \(x > 58\).
- (C) \(25 < x < 64\): all possible \(x\) satisfy this.
- (D) \(28 < x < 60\): fails at \(x = 28\) (strict inequality).
- (E) None of these: false because (C) is correct.

The answer is (C)

#agieval::aqua-rat-64source_benchmark=agieval language=en
Question: Amy is organizing her bookshelves and finds that she has 10 different types of books. She then codes each book with either a single letter or a pair of two different letters. If each type of book is uniquely represented by either a single letter or pair of letters, what is the smallest number of letters Amy will need to create the codes for all 10 types of books? (Assume the order of letters in a pair does not matter.) Answer Choices: (A)3 (B)4 (C)5 (D)10 (E)20 Think step by step, then end with a line "The answer is X" (give all correct option letters if multiple).
模型抽取答案{"a": "B", "c": 100}
归一化B
正确答案D
查看模型完整作答
The number of codes available using \(n\) letters, where codes are either a single letter or an unordered pair of distinct letters, is:

\[
n + \binom{n}{2} = n + \frac{n(n-1)}{2} = \frac{n(n+1)}{2}
\]

We need this to be at least 10 to cover all 10 types of books:

\[
\frac{n(n+1)}{2} \ge 10 \implies n(n+1) \ge 20
\]

Check values:
- For \(n = 3\): \(3 \times 4 = 12\), \(\frac{12}{2} = 6 < 10\)
- For \(n = 4\): \(4 \times 5 = 20\), \(\frac{20}{2} = 10 \ge 10\)

Thus, the smallest number of letters needed is 4.

The answer is B

Confidence: 100

#agieval::gaokao-mathqa-116source_benchmark=agieval language=zh
问题：若曲线 $y=x^{-\frac{1}{2}}$ 在点 $\left( a, a^{-\frac{1}{2}}\right)$ 处的切线与两个坐标围成的三角形 的面积为 18 , 则 $a=$ ($\qquad$)\\ 选项：(A)64 (B)32 (C)16 (D)8 请逐步思考，并在最后一行给出“答案是X”（多选时给出所有正确选项字母）。
模型抽取答案{"a": "A", "c": 100}
归一化A
正确答案D
查看模型完整作答
首先，求曲线 \(y = x^{-\frac{1}{2}}\) 的导数：
\[
y' = -\frac{1}{2}x^{-\frac{3}{2}}
\]
在点 \((a, a^{-\frac{1}{2}})\) 处的切线斜率为 \(m = -\frac{1}{2}a^{-\frac{3}{2}}\)。

切线方程为：
\[
y - a^{-\frac{1}{2}} = -\frac{1}{2}a^{-\frac{3}{2}}(x - a)
\]
求 \(x\) 截距（令 \(y = 0\)）：
\[
- a^{-\frac{1}{2}} = -\frac{1}{2}a^{-\frac{3}{2}}(x - a) \implies 2a = x - a \implies x = 3a
\]
求 \(y\) 截距（令 \(x = 0\)）：
\[
y - a^{-\frac{1}{2}} = -\frac{1}{2}a^{-\frac{3}{2}}(-a) \implies y = a^{-\frac{1}{2}} + \frac{1}{2}a^{-\frac{1}{2}} = \frac{3}{2}a^{-\frac{1}{2}}
\]
三角形面积为：
\[
S = \frac{1}{2} \times |x\text{截距}| \times |y\text{截距}| = \frac{1}{2} \times 3a \times \frac{3}{2}a^{-\frac{1}{2}} = \frac{9}{4}a^{\frac{1}{2}}
\]
令 \(S = 18\)：
\[
\frac{9}{4}\sqrt{a} = 18 \implies \sqrt{a} = 8 \implies a = 64
\]
答案是A

正确答案D
查看模型完整作答
根据核反应中的电荷数（Z）和质量数（A）守恒，我们可以列出方程。

设 X 的电荷数为 \(Z_X\)，质量数为 \(A_X\)；Y 的电荷数为 \(Z_Y\)，质量数为 \(A_Y\)。

第一个反应：\(X + ^{14}_{7}\mathrm{N} \rightarrow Y + ^{17}_{8}\mathrm{O}\)
质量数守恒：\(A_X + 14 = A_Y + 17 \Rightarrow A_X - A_Y = 3\)  (1)
电荷数守恒：\(Z_X + 7 = Z_Y + 8 \Rightarrow Z_X - Z_Y = 1\)   (2)

第二个反应：\(Y + ^{7}_{3}\mathrm{Li} \rightarrow 2X\)
质量数守恒：\(A_Y + 7 = 2A_X\)  (3)
电荷数守恒：\(Z_Y + 3 = 2Z_X\)  (4)

联立方程求解：
由(3)得 \(A_Y = 2A_X - 7\)，代入(1)：
\(A_X - (2A_X - 7) = 3 \Rightarrow -A_X + 7 = 3 \Rightarrow A_X = 4\)
代入(1)得 \(A_Y = 1\)。

由(4)得 \(Z_Y = 2Z_X - 3\)，代入(2)：
\(Z_X - (2Z_X - 3) = 1 \Rightarrow -Z_X + 3 = 1 \Rightarrow Z_X = 2\)
代入(2)得 \(Z_Y = 1\)。

因此，X 的电荷数 \(Z = 2\)，质量数 \(A = 4\)（即α粒子）；Y 的电荷数 \(Z = 1\)，质量数 \(A = 1\)（即质子）。选项 (A) 给出的是 Y 的数据，并非 X。根据常见题目设置，正确选项应为 \(Z=2, A=4\)，通常对应选项 (B)。

答案是B

模型抽取答案{"a": "ACDEF", "c": 100}

跨膜电流的平均值可以通过电容器的电荷变化量与时间的比值求得。已知电容 \(C = 1 \times 10^{-8} \, \text{F}\)，时间 \(\Delta t = 2 \, \text{ms} = 2 \times 10^{-3} \, \text{s}\)，电势差从 \(-70 \, \text{mV}\) 变为 \(30 \, \text{mV}\)，变化量 \(\Delta V = 30 - (-70) = 100 \, \text{mV} = 0.1 \, \text{V}\)。  
电荷变化量 \(\Delta Q = C \cdot \Delta V = 1 \times 10^{-8} \times 0.1 = 1 \times 10^{-9} \, \text{C}\)。  
平均电流 \(I = \frac{\Delta Q}{\Delta t} = \frac{1 \times 10^{-9}}{2 \times 10^{-3}} = 5 \times 10^{-7} \, \text{A}\)。  
因此选择(D)。
