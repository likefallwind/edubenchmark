Amy needs to create unique codes for 10 types of books using either a single letter or an unordered pair of distinct letters. If she has \(n\) letters available, the number of possible codes is the sum of single letters and pairs:

\[
n + \binom{n}{2} = n + \frac{n(n-1)}{2} = \frac{n(n+1)}{2}

Thus, the smallest number of letters needed is 4.
