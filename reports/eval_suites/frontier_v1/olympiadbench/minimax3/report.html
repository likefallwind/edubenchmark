# 解答

## 第一步：化简 $f(x)$ 并求其最小值

$$f(x) = |2x+6| + |2x-4| - 11 = 2|x+3| + 2|x-2| - 11$$

由三角不等式：$|x+3| + |x-2| \geq |(x+3)-(x-2)| = 5$

等号成立当且仅当 $-3 \leq x \leq 2$。

因此 $f(x) \geq 2 \times 5 - 11 = -1$，当且仅当 $x \in [-3, 2]$ 时 $f(x) = -1$。

## 第二步：转化条件

"$g(x+t) \leq f(x)$ 恒成立" 等价于：对所有 $x \in \mathbb{R}$，

$$|2x+6| + |2x-4| - 11 + |x+t-1| \geq 0$$

## 第三步：分析约束条件

记 $h(x) = f(x) + |x+t-1|$。

**在 $x \in [-3, 2]$ 上**：$f(x) = -1$，所以 $h(x) = |x+t-1| - 1$。

要使 $h(x) \geq 0$ 对所有 $x \in [-3, 2]$ 成立，即

$$|x+t-1| \geq 1, \quad \forall x \in [-3, 2]$$

此时 $x+t-1 \in [t-4, t+1]$，需满足区间 $[t-4, t+1] \subseteq (-\infty, -1] \cup [1, +\infty)$。

这要求：
- $t+1 \leq -1$，即 $t \leq -2$；或
- $t-4 \geq 1$，即 $t \geq 5$。

## 第四步：验证 $x \notin [-3, 2]$ 的情形

**当 $x > 2$ 时**：$f(x) = 4x - 9$
- $t \leq -2$：此时 $1-t \geq 3$，分两段讨论可得 $h(x) \geq 0$。
- $t \geq 5$：此时 $1-t \leq -4$，$h(x) = 4x-9 + x+t-1 = 5x+t-10 \geq 5(2)+5-10 = 5 \geq 0$ ✓

**当 $x < -3$ 时**：$f(x) = -4x - 13$
- $t \leq -2$：此时 $1-t \geq 3$，$h(x) = -4x-13 - x - t + 1 = -5x-12-t \geq 0$ ✓
- $t \geq 5$：此时 $1-t \leq -4$，$h(x) = -4x-13 + x+t-1 = -3x-14+t \geq 9-14+5 = 0$ ✓

## 第五步：边界验证

**$t = -2$**：$g(x-2) = -|x-3|$，在 $x \in [-3,2]$ 上 $|x-3| \geq 1$，等号在 $x=2$ 成立，此时 $g(0)=-1=f(2)$ ✓

**$t = 5$**：$g(x+5) = -|x+4|$，在 $x \in [-3,2]$ 上 $|x+4| \geq 1$，等号在 $x=-3$ 成立，此时 $g(2)=-1=f(-3)$ ✓

**$t = -1$（应失败）**：$g(x-1) = -|x-2|$，在 $x=2$ 处 $g(1)=0 > f(2)=-1$ ✗

**$t = 4$（应失败）**：$g(x+4) = -|x+3|$，在 $x=-3$ 处 $g(1)=0 > f(-3)=-1$ ✗

## 结论

综上，$t$ 的取值范围为 $t \leq -2$ 或 $t \geq 5$。

所以最终答案是 $\boxed{t \in (-\infty, -2] \cup [5, +\infty)}$。
