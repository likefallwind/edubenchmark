基准介绍

MOOCCube（Yu et al., ACL 2020，学堂在线）知识图谱里 905 条专家标注的先修边（425 个数学/计算机概念）当金标，构造两类题、100% 规则判分——无裁判、无抽取模型。

① 先修选择（200 题）：给概念 Y，问学它之前必须先掌握哪一个。干扰项一律同领域，其中最多两个是 Y 的**后继**概念（方向反转陷阱：Y 才是它们的先修）——只靠“听起来相关”选不对，必须懂方向。随机基线 0.25。

② 学习顺序排序（100 题）：4-6 个有依赖的概念打乱，要求排出满足全部先修约束的顺序（任意合法拓扑序均算对，部分分 = 满足的约束比例）。每题随机打乱的通过概率在出题时精确枚举，只保留 ≤5% 的题。

headline accuracy = 两类题的整体正确率；extra_metrics.score_10 做了**随机基线校正**（随机作答得 0 分）。注意：这测的是学科知识结构层面的路径，不是针对某个学生当前状态的个性化路径规划。

思考：
1.  **分析关系方向**：题目要求找出“IP 地址”的**先修概念**（Prerequisite），即学习 IP 地址之前必须先掌握的概念。也就是说，IP 地址依赖于该概念，或者该概念在知识图谱或学习路径中位于 IP 地址的前面。
2.  **分析选项 A (入侵防御系统)**：IPS 是一种安全设备，用于检测和阻止恶意活动。理解 IPS 的功能（如 ACL、状态监测）通常需要理解 IP 协议地址作为识别网络流的基础。因此，IPS 是 IP 地址的**应用**或**后续**（Master IP -> Master IPS），而不是先修概念。
3.  **分析选项 B (域名)**：域名是 DNS 系统的组成部分，作用是将人类可读的名称映射为 IP 地址。通常的学习路径是先理解 IP 地址（数值标识），再通过 DNS 学习域名（文本标识）。域名依赖于 IP 地址的存在，因此域名是**后续**概念，不是先修。
4.  **分析选项 C (跟踪)**：“跟踪”通常指视频分析领域（Compute Vision），与计算机网络（IP 地址）领域无直接逻辑依赖关系，属于干扰项。
5.  **分析选项 D (最大传输单元 - MTU)**：MTU 是数据链路层与网络层交互的关键概念。在 OSI 七层模型的网络学习路径中，通常是先学习物理层和数据链路层（涉及数据封装、帧的最大长度，即 MTU），再学习网络层（IP 地址）。定义中明确提到“链路帧可以封装的 IP 分组”，表明数据包（MTU 概念）和网络地址（IP）之间存在层级依赖。从逻辑构建上讲，理解数据如何在网络中传输的**容量限制（MTU）**通常是理解**网络层如何标记数据包（IP 地址）**的地基。相比之下，A、B 都是 IP 建立后的上层应用。
6.  **结论**：MTU 属于更底层的网络传输参数概念，在知识体系中位于 IP 地址之前。
