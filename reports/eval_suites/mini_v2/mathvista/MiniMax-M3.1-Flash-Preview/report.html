基准介绍

MathVista 评测视觉语境下的数学推理能力，题目把图表、几何图形、函数曲线、自然/学术图片等视觉信息与数学问题结合，模型必须先看懂图、再完成推理与计算。对应本仓库能力维度 D06（多模态教育理解）。

本次使用官方 testmini 划分（1000 题），题型分为选择题（multi_choice）与自由作答（free_form），答案类型涵盖整数、浮点数、文本与列表，并按任务（几何求解、图表问答、数学应用题、教材问答、视觉问答）分桶统计。

答案抽取与判分沿用官方 evaluation 流程：先走快速路径，再由 LLM 从模型自由作答中抽取最终答案，最后做答案类型归一化与就近选项匹配。

主页：https://mathvista.github.io/

#333question_type=multi_choice answer_type=text task=geometry problem solving
Hint: Please answer the question and provide the correct option letter, e.g., A, B, C, D, at the end. Question: Find tan X Choices: (A) \frac { 5 } { 12 } (B) \frac { 12 } { 13 } (C) \frac { 17 } { 12 } (D) \frac { 12 } { 5 }
  • A. \frac { 5 } { 12 }
  • B. \frac { 12 } { 13 }
  • C. \frac { 17 } { 12 }
  • D. \frac { 12 } { 5 }
模型抽取答案D
归一化\frac { 12 } { 5 }
正确答案\frac { 5 } { 12 }
查看模型完整作答
The missing leg is

\[
\sqrt{13^2-5^2}=\sqrt{169-25}=12.
\]

For angle \(X\), the opposite side is \(12\) and the adjacent side is \(5\). Thus,

\[
\tan X=\frac{12}{5}.
\]

**D**
