模型抽取答案\boxed{0,1,2,3,4,\frac{1}{39},\frac{8}{39},\frac{28}{65},\frac{56}{195},\frac{2}{39}}

查看模型完整作答
首先，根据题意，总体由 \(n\) 个超大城市和 \(8\) 个小城市组成，总城市数为 \(n+8\)。  
一次抽取 \(2\) 个城市，全是小城市的概率为
\[
\frac{\binom{8}{2}}{\binom{n+8}{2}} = \frac{4}{15}.
\]
计算得 \(\binom{8}{2}=28\)，所以
\[
\frac{28}{\binom{n+8}{2}} = \frac{4}{15} \implies \binom{n+8}{2} = \frac{28 \times 15}{4} = 105.
\]
又 \(\binom{n+8}{2} = \frac{(n+8)(n+7)}{2} = 105\)，得
\[
(n+8)(n+7) = 210 \implies n^2 + 15n - 154 = 0.
\]
解得 \(n = 7\)（舍去负值）。因此总共有 \(7\) 个超大城市，\(8\) 个小城市，合计 \(15\) 个城市。

若一次抽取 \(4\) 个城市，设抽取的小城市个数为 \(X\)，则 \(X\) 服从超几何分布，可能取值为 \(0,1,2,3,4\)。  
总抽取方法数为 \(\binom{15}{4} = 1365\)。  
相应概率为
\[
P(X=k) = \frac{\binom{8}{k}\binom{7}{4-k}}{\binom{15}{4}}, \quad k=0,1,2,3,4.
\]
具体计算如下：
\[
\begin{aligned}
P(X=0) &= \frac{\binom{8}{0}\binom{7}{4}}{1365} = \frac{35}{1365} = \frac{1}{39}, \\
P(X=1) &= \frac{\binom{8}{1}\binom{7}{3}}{1365} = \frac{280}{1365} = \frac{8}{39}, \\
P(X=2) &= \frac{\binom{8}{2}\binom{7}{2}}{1365} = \frac{588}{1365} = \frac{28}{65}, \\
P(X=3) &= \frac{\binom{8}{3}\binom{7}{1}}{1365} = \frac{392}{1365} = \frac{56}{195}, \\
P(X=4) &= \frac{\binom{8}{4}\binom{7}{0}}{1365} = \frac{70}{1365} = \frac{2}{39}.
\end{aligned}
\]
经验证，所有概率之和为 \(1\)。

所以最终答案是\(\boxed{0,1,2,3,4,\frac{1}{39},\frac{8}{39},\frac{28}{65},\frac{56}{195},\frac{2}{39}}\)。
#OE_TO_maths_zh_COMP-391subject=Math language=zh modality=TO answer_type=Interval
以下是中国数学竞赛中的解答题，答案类型为区间。请根据题目的要求和所提供的信息计算得出答案。解答过程和结果中使用的变量和公式请使用LaTeX格式表示。请在最后以“所以最终答案是\boxed{答案}。”显式给出结果。 已知函数 $f(x)=|x-1|+|x-2|$. 求不等式 $f(x) \geq 3$ 的解集.
模型抽取答案\boxed{(-\infty,0] \cup [3,+\infty)}
归一化(-\infty,0] \cup [3,+\infty)
正确答案$(-\infty, 0] \cup [3, +\infty)$
查看模型完整作答
要解不等式 \( f(x) = |x-1| + |x-2| \geq 3 \)，我们需要根据绝对值的零点 \(x=1\) 和 \(x=2\) 将定义域分为三个区间进行讨论。

**情况 1：** \(x < 1\)
此时 \(x-1 < 0\)，\(x-2 < 0\)，所以
\[
f(x) = (1 - x) + (2 - x) = 3 - 2x.
\]
解不等式 \(3 - 2x \geq 3\)：
\[
-2x \geq 0 \implies x \leq 0.
\]
结合前提条件 \(x < 1\)，得该区间的解为 \(x \leq 0\)，即 \((-\infty, 0]\)。

**情况 2：** \(1 \leq x \leq 2\)
此时 \(x-1 \geq 0\)，\(x-2 \leq 0\)，所以
\[
f(x) = (x - 1) + (2 - x) = 1.
\]
解不等式 \(1 \geq 3\)，该不等式不成立，故此区间无解。

**情况 3：** \(x > 2\)
此时 \(x-1 > 0\)，\(x-2 > 0\)，所以
\[
f(x) = (x - 1) + (x - 2) = 2x - 3.
\]
解不等式 \(2x - 3 \geq 3\)：
\[
2x \geq 6 \implies x \geq 3.
\]
结合前提条件 \(x > 2\)，得该区间的解为 \(x \geq 3\)，即 \([3, +\infty)\)。

综合以上三种情况，不等式 \(f(x) \geq 3\) 的解集为各个区间解的并集：
\[
(-\infty, 0] \cup [3, +\infty).
\]

所以最终答案是\boxed{(-\infty,0] \cup [3,+\infty)}。
