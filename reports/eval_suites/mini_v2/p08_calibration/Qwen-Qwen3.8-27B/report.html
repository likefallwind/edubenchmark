基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

#agieval::aqua-rat-114source_benchmark=agieval language=en
Question: If n is such that 36 ≤ n ≤ 72, then x = (n2 + 2√n(n + 4) + 16) / (n+ 4√n+ 4) satisfies Answer Choices: (A)20 < x < 54 (B)23 < x < 58 (C)25 < x < 64 (D)28 < x < 60 (E)None of these Think step by step, then end with a line "The answer is X" (give all correct option letters if multiple).
模型抽取答案{"a": "C", "c": 75}
归一化C
正确答案D
查看模型完整作答
Let \(t=\sqrt n\). Since \(36\le n\le 72\),

\[
6\le t\le \sqrt{72}=6\sqrt2.
\]

Rewrite the expression in terms of \(t\):

\[
x=\frac{n^2+2\sqrt n(n+4)+16}{n+4\sqrt n+4}
=\frac{t^4+2t(t^2+4)+16}{t^2+4t+4}.
\]

The numerator factors nicely:

\[
t^4+2t^3+8t+16=(t+2)(t^3+8)=(t+2)^2(t^2-2t+4).
\]

The denominator is

\[
t^2+4t+4=(t+2)^2.
\]

So

\[
x=t^2-2t+4=n-2\sqrt n+4.
\]

Since \(t\ge 6\), the function \(t^2-2t+4\) is increasing. Thus:

- Minimum at \(t=6\):

\[
x_{\min}=36-12+4=28.
\]

- Maximum at \(t=6\sqrt2\):

\[
x_{\max}=72-12\sqrt2+4=76-12\sqrt2\approx 59.03.
\]

So the actual range is

\[
28\le x<60.
\]

Now check the options:

- (D) says \(28<x<60\), but at \(n=36\), \(x=28\), so the strict inequality \(28<x\) fails.
- (C) says \(25<x<64\), which is definitely true for all allowed \(n\).

Thus, as written, the strictly correct choice is (C).

The answer is C

#agieval::aqua-rat-64source_benchmark=agieval language=en
Question: Amy is organizing her bookshelves and finds that she has 10 different types of books. She then codes each book with either a single letter or a pair of two different letters. If each type of book is uniquely represented by either a single letter or pair of letters, what is the smallest number of letters Amy will need to create the codes for all 10 types of books? (Assume the order of letters in a pair does not matter.) Answer Choices: (A)3 (B)4 (C)5 (D)10 (E)20 Think step by step, then end with a line "The answer is X" (give all correct option letters if multiple).
模型抽取答案{"a": "B", "c": 100}
归一化B
正确答案D
查看模型完整作答
We need enough unique codes from a set of \(n\) letters.

A code can be:

- a single letter: \(n\) choices
- a pair of two different letters, where order does not matter: \(\binom{n}{2}\) choices

So the total number of possible codes is

\[
n + \binom{n}{2} = n + \frac{n(n-1)}{2} = \frac{n(n+1)}{2}.
\]

We need at least 10 unique codes:

\[
\frac{n(n+1)}{2} \ge 10.
\]

Check small values:

- \(n=3\): \(\frac{3\cdot4}{2}=6\), not enough.
- \(n=4\): \(\frac{4\cdot5}{2}=10\), exactly enough.

Thus, the smallest number of letters needed is 4.

The answer is B
Confidence: 100

由题干可知：

1. 兵马俑若“供研究使用”，就必须采用防护液和单体渗透这两套方法进行保护。  
2. 一旦采用这两套方法保护，就会破坏研究者可能从中获得的有关秦代彩绘技术的全部信息。

因此：

- 如果某个兵马俑被用于研究秦代军人服色，那么它必然已经采取了保护方法。

D 项“没有保护的能提供更多”不能必然推出，因为未保护的也不能供研究使用，且不一定总体信息更多。
