基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

To solve the problem, we need to calculate the total number of unique codes Amy can create with `n` letters, where codes are either single letters or unordered pairs of distinct letters. We need this total to be at least 10 (one for each book type).
### Step 1: Define the total number of codes
- **Single-letter codes**: There are `n` unique single-letter codes (one for each letter).
- **Unordered pairs of distinct letters**: Since order does not matter, this is the number of combinations of `n` letters taken 2 at a time, calculated as `C(n, 2) = n(n-1)/2`.
Total codes = number of single-letter codes + number of unordered pair codes = `n + n(n-1)/2`.
### Step 2: Test small values of `n`
We test increasing values of `n` to find the smallest `n` where total codes ≥ 10:
1.  For `n=3`:
    - Single-letter codes: 3
    - Pair codes: `C(3,2) = 3(3-1)/2 = 3`
    - Total: `3 + 3 = 6`, which is less than 10. Insufficient.
2.  For `n=4`:
    - Single-letter codes: 4
    - Pair codes: `C(4,2) = 4(4-1)/2 = 6`
    - Total: `4 + 6 = 10`, which exactly matches the number of book types. Sufficient.
### Step 3: Verify
For `n=4` (letters A, B, C, D), the full set of codes is: A, B, C, D, AB, AC, AD, BC, BD, CD. This is 10 unique codes, which covers all 10 book types.
The answer is B
