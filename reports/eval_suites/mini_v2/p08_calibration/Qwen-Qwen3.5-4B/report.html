基准介绍

P08（置信度校准与弃答）的 v1：零新增标注。复用 ceval / mmlu_pro / agieval / mathtutorbench_problem_solving 的既有判分，在原题后追加置信度诱导，测模型自报置信度与实际对错的一致性——即“自信地教错”这一最致命失效模式的直接测量。

题目由难度分层抽样器（依据既有 scored.jsonl 的集成难度，easy/mixed/hard≈30/50/20）固定成一份 item_list，所有模型经 --item-list 跑同一套题，保证跨模型可比与公平（难度来自历史模型集成，绝不用被测模型自身错题）。

指标：CWR（高置信错答率）、ECE、Brier、AUROC、选择性准确率；headline score_10 = 10×[0.5×(1−CWR)+0.5×AUROC]，与纯正确率可分离。难度加权集上的绝对值仅用于模型间相对比较，不作自然分布下的绝对宣称。

To find the smallest number of letters Amy needs, we calculate how many unique codes can be generated using $n$ letters following the given rules.

1.  **Count Single-Letter Codes**:
    If there are $n$ letters available, the number of unique single-letter codes is simply $n$.

2.  **Count Pair Codes**:
    The codes must be pairs of two *different* letters, and the order does *not* matter. This is a combination problem where we select 2 items from a set of $n$. The formula for this is $\binom{n}{2}$:
    $$ \binom{n}{2} = \frac{n(n-1)}{2} $$

3.  **Total Unique Codes**:
    The total number of unique codes possible with $n$ letters is the sum of single-letter codes and pair codes:
    $$ \text{Total Codes} = n + \frac{n(n-1)}{2} $$

4.  **Inequality**:
    We need at least 10 unique codes to represent the 10 types of books. Therefore:
    $$ n + \frac{n(n-1)}{2} \ge 10 $$
    Multiply by 2 to clear the fraction:
    $$ 2n + n^2 - n \ge 20 $$
    $$ n^2 + n \ge 20 $$

5.  **Evaluate Integers for $n$**:
    *   **If $n = 3$**: $(3)^2 + 3 = 9 + 3 = 12$. Since $12 < 20$, 3 letters are insufficient.
    *   **If $n = 4$**: $(4)^2 + 4 = 16 + 4 = 20$. Since $20 \ge 20$, 4 letters are sufficient.

    Verification for $n=4$:
    *   Single codes: A, B, C, D (4 codes)
    *   Pair codes: AB, AC, AD, BC, BD, CD ($\frac{4 \times 3}{2} = 6$ codes)
    *   Total: $4 + 6 = 10$ codes.

The smallest number of letters required is 4. This corresponds to option (B).

The answer is (B)
