#gaokao-mathcloze-25task=gaokao-mathcloze language=zh question_type=cloze
问题：已知 $a, b, c$ 分别为 $\triangle A B C$ 的三个内角 $A, B, C$ 的对边, $a=2$ 且 $(2+b)(\sin A-\sin B)=(c-b) \sin C$, 则 $\triangle A B C$ 面积的最大值为 $(\quad)$. 请逐步推导，并在最后用 \boxed{} 给出最终答案。
模型抽取答案\sqrt{3}
归一化\sqrt{3}
正确答案$\sqrt{3}$
查看模型完整作答
已知条件为三角形 \( \triangle ABC \) 中，\( a = 2 \) 且  
\[
(2+b)(\sin A - \sin B) = (c-b)\sin C.
\]  
利用正弦定理 \(\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R\)，将 \(\sin A, \sin B, \sin C\) 用边长表示并代入等式，两边同乘 \(2R\) 得  
\[
(2+b)(a - b) = (c-b)c.
\]  
代入 \(a = 2\)，化简为  
\[
(2+b)(2-b) = c(c-b) \quad\Longrightarrow\quad 4 - b^2 = c^2 - bc,
\]  
即  
\[
b^2 + c^2 - bc = 4.
\]  
又由余弦定理得 \(a^2 = b^2 + c^2 - 2bc\cos A\)，即  
\[
4 = b^2 + c^2 - 2bc\cos A.
\]  
对比两式可得  
\[
-2bc\cos A = -bc \quad\Longrightarrow\quad \cos A = \frac{1}{2},
\]  
所以 \(A = \frac{\pi}{3}\)。  
三角形面积  
\[
S = \frac{1}{2}bc\sin A = \frac{\sqrt{3}}{4}bc.
\]  
在条件 \(b^2 + c^2 - bc = 4\) 下求 \(bc\) 的最大值。由基本不等式 \(b^2 + c^2 \ge 2bc\)，得  
\[
4 = b^2 + c^2 - bc \ge 2bc - bc = bc,
\]  
即 \(bc \le 4\)，当且仅当 \(b = c = 2\) 时取等号，此时满足三角形边长条件。  
代入面积公式得最大面积  
\[
S_{\text{max}} = \frac{\sqrt{3}}{4} \times 4 = \sqrt{3}.
\]

\boxed{\sqrt{3}}

#math-246task=math language=en question_type=cloze
Question: If $f(x)$ is an even function and $g(x)$ is an odd function, find if $f(g(x^3))$ is even, odd, or neither. Enter "odd", "even", or "neither". Reason step by step, then give the final answer in \boxed{}.
模型抽取答案even
归一化even
正确答案\text{even}
查看模型完整作答
The function \(h(x) = f(g(x^3))\) is evaluated for parity by examining \(h(-x)\):

\[
h(-x) = f(g((-x)^3)) = f(g(-x^3))
\]

Since \(g\) is odd, \(g(-x^3) = -g(x^3)\). Then:

\[
h(-x) = f(-g(x^3))
\]

Since \(f\) is even, \(f(-y) = f(y)\) for all \(y\). Substituting \(y = g(x^3)\):

\[
h(-x) = f(g(x^3)) = h(x)
\]

Thus, \(h\) is an even function.

\boxed{even}
